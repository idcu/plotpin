## 维护规则

1. 关闭一项时改状态并在对应任务记录里留证据（命令 + 输出摘要），不得只改文字。
2. 新增债务从 **R-36** 起编号，按「问题 / 影响 / 证据 / 建议」四列追加，不覆盖历史行。
3. 删除系统性能力时同步登记 `docs/deletions.md`，由 `check-deletions.mjs` 守。
4. 本表只做索引，不复述 `known-issues.md` 的条目正文；两者冲突时以代码与门禁实测为准。
