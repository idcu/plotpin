# 功能说明（features）

> **读者**：产品、测试、使用者，以及要判断“这个功能到底承诺什么”的开发者。
> **回答**：用户可感知的功能域、行为口径、明确限制、哪些能力未验证。
> **不回答**：代码实现见 [ARCHITECTURE](ARCHITECTURE.md)，逐文件接口见 [modules](modules.md)，操作步骤见 [user-guide](user-guide.md)。
> **口径**：行为以当前代码为准，核对 2026-11-13（基线 `2123a46` + M1/M2 修复）。容量/精度等数字统一在 [engineering](engineering.md)§6 与 [facts](facts.md)，本文不重复复制。
> **验证边界**：自动化只实测 Chromium；Firefox/WebKit/Safari 未验证，见 [testing](testing.md)§3。

## 1. 产品定位与适用边界

- 离线、免安装的图纸标注工具：底图校准、设备点位、真实比例区域/折线、尺寸标注、统计与导出。
- 数据保存在本机浏览器；无账号、无服务器、无网络请求。协作仅限本机多标签或局域网直连。
- 支持范围：Chromium 是当前唯一有可复跑自动化证据的浏览器；Firefox 历史记录未复跑，Safari 原生未验证，WebKit on Windows 不作支持目标。
- 明确的非目标：不做消防/规范审图，不做 CAD 全量编辑，不承诺无限容量，不做云端同步。

## 2. 画布与视图

- **入口**：主画布；顶栏 `−` / `适应` / `＋`；左下角缩放百分比与坐标读数。
- **能力**：滚轮缩放、适应窗口、右键/中键/空格拖拽平移、网格（线距为网格大小的整数倍，交点均可吸附）、十字准星、点图标显示大小滑杆。
- **绘制顺序固定**：图片底图 → 矢量场地 → 网格/覆盖率覆盖 → 场地标注 → 坐标轴 → 业务对象 → 选择/编辑手柄。取景框覆盖图片与场地的并集。
- **限制**：万级对象时缩放/平移依赖静态层缓存；大规模点选仍可能触发静态层重建而卡顿。移动端真机手势未验证。

## 3. 对象、类型与编号

- **入口**：左侧工具栏 12 个控件（`选择` `平移` `点设备` `区域` `折线` `文字` `测距` `标注` `场地节点` `图片变换` `参考线` + `完成`）；侧栏 6 个页签（`属性` `清单` `图层/类型` `符号库` `统计` `规则`）。
- **对象类型**：点设备；区域（矩形/圆形/椭圆/扇形/平行四边形，世界坐标真实比例）；折线（可闭合为区域）；文字；尺寸标注（两点距离/多点测距/面积/角度）。`测距` 工具只做临时测量，不落为对象；需要保留请用 `标注`。
- **多边形状（M1）**：`shape.type==='polygon'` 的顶点直接存世界坐标，用于面积、周长、命中、标签中心与捕捉包围盒；少于 3 点退化时面积/周长返回 0、命中返回否、标签中心回退锚点；旋转手柄对 polygon 无定义。它不进入区域形状转换与 `sanitizeAreaShape`，正常交互不会新建该形态，主要用于兼容异常/外部写入。
- **编号**：自动编号形如 `O0001`，跨楼层查重；`清单` 支持批量重排（自定义前缀/起始/步长，自动跳过已占用编号）。矢量场地不占编号、不进清单/CSV。
- **编辑**：单击选择、框选、拖拽移动、拖节点、旋转/缩放手柄；`清单` 可改名称/坐标/参数/显隐/锁定，支持批量改图层、平移、旋转、删除、显示/隐藏标注。属性面板（对象与场地共用）只在字段获得焦点后的首次输入时记一次撤销，单纯切换字段不再占用撤销栈。`清单` 的关键字/类型/图层筛选与“全选”“表头全选”共用唯一 `filteredObjects()`；点击行只刷新属性面板与选中高亮，不重建整表。
- **类型与图层**：图层可新增/改名/显隐/锁定；类型可自定义类别、颜色、图标与物理尺寸图形（圆/方/扇形/杆）。每层共用图层与类型。载入时重复图层 id 只保留首个定义。
- **标注**：对象级标注含编号、坐标、基点、半径、边长、顶点、周长、面积、节点、段长；默认值沿用旧全局观感，可按对象覆盖。段长标注可设最小屏幕像素（默认 26 px，范围 10–60）。
- **限制**：楼层名必须唯一；新增/重命名重名会被拒绝，导入会因重名楼层整批拒绝。导入的对象标识/编号已在读入时去重（重复 id 追加 `_2` 后缀，重名对象走编号作用域）。
- **导出口径**：CSV/TSV/XLSX 台账保留全量对象，“显示”列按**有效可见**（对象 `visible` 且所属图层 `visible`）标注，表头不变；PNG/SVG/DXF、PDF 图纸页与 PDF 清单只输出有效可见对象。草稿/校准属于交互瞬态，默认不进入 PNG/PDF 产物。
- **DXF 保真导出**：默认 DXF 与旧版本逐字节一致；保真导出为显式选项，仅椭圆输出为 ELLIPSE；部分 CAD 对 ELLIPSE 的解释可能不同，不承诺与原生 CAD 的编辑体验一致。

## 4. 校准与坐标

- **入口**：顶栏 `比例尺`（两点定标）、`仿射校准`（2 点=旋转+等比相似，≥3 点=最小二乘完整仿射）；左侧 `图片变换`（平移/旋转/等比缩放/切变，图片角点可吸附场地角）。
- **前置**：仅图片底图需要校准；矢量场地以自身坐标为基准。入口不可用时会禁用并显示原因（图片解码中、底图缺失、无图片底图等）。
- **场地优先**：存在矢量场地时，图片校准只改图片与业务对象，场地坐标不自动迁移；无场地时保持原行为。
- **限制**：2×3 仿射不提供四角自由拖拽（不能表达任意透视）。切变手柄在图片自身坐标系内求解；旋转到 89°/90°/91° 行为一致，不会因世界竖直投影退化而跳变。
- **形状迁移**：一般仿射（不等比/切变/旋转）下，圆与椭圆按精确主轴成像（正交共轭直径优先，否则 SVD），对象与场地共用同一实现；平行四边形按映射后的两条边向量重算宽/高/倾角/朝向。扇形仅在正向相似变换（旋转+等比缩放）下精确；其余情况按面积保真（半径 ×√|det|）近似并标记为降级（`sector-affine`），变换摘要的 `degraded` 会列出受影响对象。既有已校准坐标不做迁移，只对后续新应用的变换生效。
- **边界防护**：图片切变斜率夹取到 ±50（约 88.9°）；图片高度或底边长度退化为 0、或变换非有限时，切变确定性降级为无操作并原样保留变换；任何非有限结果都拒绝应用；`fitView()` 缩放夹取到 `ZOOM_MIN~ZOOM_MAX`；折线/多边形单对象顶点上限 10000，超出拒绝并提示；包围盒逐点计算，超大点列不再因 `Math.min(...points)` 展开而爆栈。
- **形状转换**：椭圆→矩形保留原旋转角与 `2rx×2ry` 本地框；圆→矩形因角度无意义归零；平行四边形→矩形保留角度。
- **底图绘制失败**：`drawImage` 抛错不再静默吞掉，置 `bgImageState='error'` 并只提示一次；替换底图后可恢复，连续失败不刷 toast。
- **瞬态清理**：载入工程、撤销/重做、切换楼层、快照回滚、协作合并、Esc 中断、窗口失焦统一调用 `resetTransientInteractionState()`，清空草稿、拖拽、框选、捕捉高亮/热键、参考线与覆盖率叠加；快照回滚保留比例尺校准点，但清空仿射校准草稿。Esc 中断保留覆盖率叠加；窗口失焦只结束进行中的交互，保留校准点、参考线与覆盖率。

## 5. 双槽位：图片底图 + 矢量场地

- **入口**：顶栏 `底图/场地`；左侧 `场地节点`；`属性` 面板编辑场地参数。
- **槽位**：每层最多 1 张图片底图 + 1 个矢量场地，互不覆盖。场地支持矩形/圆形/椭圆/扇形/平行四边形/多边形。
- **场地能力**：拖节点改形；属性面板精确输入；场地标注（节点、段长、基点、半径、面积/周长）可逐项开关；场地参与捕捉；场地不参与选择/框选/对象计数。统计页的“场地参数”直接取 `siteDescriptionParts()` 的结构化 `detail`，中英文模式显示同一份参数。
- **渲染与导出**：画布、PNG、PDF、SVG、DXF 均输出场地；SVG 补齐节点/段长/半径/面积周长；DXF 输出到独立 `SITE` 图层；CSV/XLSX 不增加场地行。替换图片底图时强制重置旧图的仿射变换与校准标记，`metersPerPixel` 回退默认 0.05，必须重新校准后才能按真实比例测量。
- **兼容**：旧工程中类型为图片的底图原样保留且无场地；其它旧底图类型迁移为场地。可读取 v1/v2 工程；旧版应用对新增场地数据的忽略不在兼容承诺内。场地的 `id` 按对象同一规则清洗，`annot` 只保留已知布尔键。
- **扇形跨 0°**：起止角统一由 `sectorArcRange()` 归一为“起角 a0 → a0+有效张角”，画布、SVG、控制点共用；`350°→20°` 在屏幕与导出中都是 30°。场地编辑与清空进入撤销栈、自动保存并广播给协作方；远端清空场地会在状态栏提示且可 Ctrl+Z 恢复。

## 6. 测量、统计与分析

- **测距/标注**：逐点单击、双击结束；实时显示段长与累计总长；标注对象可保存并导出。
- **统计页签**：对象数量、面积、长度、楼层汇总，以及一组基础问题检查（尺寸过小、节点不足、自相交、超出场地等）。它是快速自检，不等同于 `规则` 页签的几何检查；基础问题检查只统计**可见**对象，隐藏对象的问题不计入。
- **覆盖率分析**：顶栏 `覆盖率分析`；按固定目标格数（默认值见 [engineering](engineering.md)§6）估算可见区域覆盖率，高亮盲区，可导出盲区 GeoJSON。GeoJSON 坐标按当前精度取整，外环统一逆时针（RFC 7946），取整后退化的面会跳过。结果与视口缩放无关；清除叠加层、对象/楼层变更、切层、载入/撤销时结果与离屏栅格缓存一并释放。旋转方形设备的预筛盒按旋转后真实外接范围计算（半宽 `r·(|cos|+|sin|)`），0/30/45/90° 下与逐格 `pointInFootprint` 判定一致。
- **布点优化**：覆盖率结果弹窗内 `布点优化…`；输入视场半径/张角/目标覆盖率/最多新增台数，贪心给出新增点位，应用后自动重跑覆盖率。
- **停车规划**：顶栏 `停车规划`；按当前场地自动排布双面垂直车位与共用通道（场地可见时只按场地包围盒，场地隐藏才退回图片∪场地取景框）；默认车位 2.5×5.3 m、通道 6 m，通道净宽 <2.5 m 拒绝生成，<5.5 m 给出警告。
- **限制**：覆盖率是栅格估算，圆/椭圆/扇形区域面积 v3 起用解析公式（与统计面板、报告同源），但栅格命中判定仍按固定段数采样；v1/v2 与 v3 数值不可直接对比。统计页越界与规则页同口径：场地可见时按场地包围盒判、容差取规则配置（默认 0.05 m），统计页标题与 PDF 报告标注“v2”；v2 与旧版报告数值不可直接比较。PDF 清单列布局是台账子集（无楼层/备注/更新时间），多楼层清单按层分页，打印报告为单页且不标注楼层。面板盲区面积与主覆盖率同一口径（逐区域 `面积×(1-覆盖率)` 求和，严格等于 `totalBlind`）；盲区 GeoJSON 的面几何仍按盲格矩形合并，其面积用 `blindSpotRectArea` 单独汇总，属栅格几何近似，差异上界约为盲区周长×格宽/2。

## 7. 文件导入

- **入口**：顶栏 `导入`；文件也可直接拖到画布。`导入` 与拖拽走同一分发：JSON、DXF、DWG（需先转换）、PDF、CSV/TSV/TXT、XLSX、图片（png/jpg/jpeg/gif/webp/bmp/svg）以及插件注册的导入器。**拖拽只取文件列表中的第一个**，其余文件被忽略，不提示。
- **JSON**：事务化替换当前工程；失败保持原现场。跨设备导入不接管本机工程库绑定。资产回收延后到 `afterStateLoaded()` 成功之后：提交失败回滚时不会误删旧工程资产，成功导入后不可达旧资产正常回收。
- **DXF**：ASCII DXF 导入线/多段线/圆/点/文字/MTEXT 为对应对象；**ARC / ELLIPSE / SPLINE / INSERT 由解析器统一展开为折线**（弧按 25 点、椭圆闭合 65 点、样条按 De Boor 采样，块参照应用平移/缩放/旋转），导入报告如实给出“折线近似落地”条数；`SOLID / 3DFACE / LEADER / ATTRIB / ATTDEF` 由适配层补解析。`.dwg` 不支持，需另存 ASCII DXF；R12 的 `VERTEX 42` 凸度仍按折线拉直并在预检标注受影响段数（不静默丢弧）；`DIMENSION` 等未落地类型跳过，报告列明类型与条数；TEXT/ATTRIB 文本保留首尾空格。组码缺行或错位的实体（如 LINE 缺 11/21 变成零长线、圆缺 40 变成 r=0）在适配层被丢弃，预检与导入报告给出“跳过非法实体：N 个（缺少坐标或必需参数）”，不会写入错误几何；非数字组码行直接跳过，不牵连后续结构。
- **PDF**：**只导入第 1 页**（产品决策）：路径转折线/区域、文本转文字对象均来自第 1 页；多页文件导入后提示“共 N 页，已导入第 1 页”，不提供静默多页合并，也不提供合并开关。文本按“UTF-16BE/LE BOM → GBK 严格解码 → ASCII 原样”的编码链提取，纯中文不再因 ASCII 占比低被整段丢弃；解不开的文字按条计数并提示“文字 N 条无法解码，已跳过”。不解析嵌入字体的 ToUnicode/CID 字形映射，设置了该映射的 PDF 仍可能没有文字或按字节误解码，导入结果以实际文字对象为准。参数缺失或含非有限值的绘制算子整条跳过（不产生 NaN 坐标），解码失败的内嵌图不进底图；两者都按条提示“已跳过 N 个非法绘制操作 / N 张内嵌图无法解码”。底图只取第 1 页实际绘制的内嵌图（按页资源 `/XObject` + `/Name Do` 匹配），不再取全文档最大图。含 `/cm` 变换的 PDF 曲线采样与文字定位已统一到设备空间；文本字号仍按原始 `Tf` 值，缩放矩阵下的字号未同步放大。内嵌底图与图片导入走同一条内容寻址资产路径（`assetId` 入库，自动保存/重开后仍可取回）；解压上限在流式累计阶段生效，超过 64 MB 的 Flate 流与按像素尺寸估算明显超限的图像不会进入解压器。
- **图片**：作为图片底图导入；超 3000 px 长边会降采样，超大透明图可能转 JPEG。
- **限制**：单文件 32 MB、实体 10 万、表格 2 万行、对象总数 10 万；**顶点上限只在交互侧校验**（草稿与节点插入按 10000 拒绝），导入与插件写入没有统一校验，超大折线可能使包围盒计算变慢或抛错。

## 8. 表格布点与批量修改

- **入口**：`导入` 选择 CSV/TSV/XLSX；也可先导出同格式表格作为模板。
- **能力**：按表头映射编号/名称/对象类型/业务类型/楼层/坐标/尺寸/节点/图层/显隐/锁定/备注/型号等字段。存在 `操作` 列时进入严格模式：`新增`/`创建`/`更新`/`替换`；`替换` 可配合 `匹配编号`、`匹配名称`、`匹配名称包含`、`匹配对象类型`、`匹配业务类型`、`匹配图层` 条件批量改属性（不改几何）。无 `操作` 列时沿用旧自动路由（编号命中→更新，否则新增；带匹配列→替换）。
- **事务性**：严格模式出现非法行时整批不生效；预览可放弃。
- **公式注入防护**：以 `=`/`+`/`-`/`@` 等危险前缀开头的文本导出时加一个前导单引号，导入时还原；本来就以单引号开头的文本导出时再加一层，导入时只剥一层，因此 `'=SUM(A1)` 往返后仍是原文。
- **数值格式**：X/Y、角度、宽度、高度、长度、面积、形状参数（平行四边形倾角、扇形起止角）统一按 `settings.precision`（默认 2 位小数）输出；角度列与形状参数不再输出裸整数。
- **限制**：表格往返不是逐字节无损——所有单元格会去首尾空格，名称/备注的首尾空格不保留；“显示”/“锁定”的未知布尔值会保留原值并告警，“闭合”的未知值仍按“否”处理；形状参数非法时保留原几何并告警；坐标按当前精度量化，首次导出→导入可能产生不超过 0.5×10⁻ᵖ（默认 0.5 cm）的漂移，重复往返不再累积；工程存在重名楼层时整批拒绝；目标楼层 `objects` 数据异常时该行拒绝，绝不回退到当前楼层写入；单工作表超过 5 万行会被跳过（其余工作表继续导入），全部工作表都超限时才报错并提示拆分。

## 9. 多楼层、工程库与保存

- **入口**：顶栏 `新建` `工程库` `楼层` `清空`；右上角保存状态。
- **楼层**：每层独立图片底图、矢量场地与对象；图层/类型/工程名/标题栏等跨层共享。可新增、切换、重命名、删除；`清空` 清空当前楼层的底图、场地、对象与标注，可用 Ctrl+Z 撤销。
- **工程库**：把当前图纸另存为命名工程；打开/复制/删除本机工程；`合并他人工程…` 选择对方导出的 JSON 按对象更新时间合并。打开工程与 JSON 导入同一事务语义：先完成 `afterStateLoaded()` 的资产转换，成功后才回收不可达旧资产；加载阶段失败回滚现场且不删旧资产。打开与合并共用对象数上限（10 万），超限整批拒绝并保持现场。
- **保存**：修改后约 450 ms 自动保存草稿；绑定工程库后同步到工程库。打开另一工程、新建工程或导入 JSON 前都会先强制落盘当前工程：清掉防抖/重试定时器并立即保存；若另一标签占用租约或保存失败，取消该操作并提示，不再静默丢最后一次编辑。撤销栈 20 步。存储不可用时降级并提示，应导出 JSON 备份。
- **设置来源**：打开工程后以工程内保存的设置为准；本机设置只在没有已保存工程时兜底，避免跨工程覆盖。
- **限制**：楼层名唯一（新增/重命名重名被拒；旧工程重名加载只告警，导入整批拒绝）；删除图层/类型前检查全部楼层引用，有引用时确认后迁移到默认图层 / 同类内置类型，并对所有受影响对象（含非当前楼层）单调打点，协作合并不会回退到旧引用。加载审计按对象的 `layerId` 判定未知图层；结构非法而被丢弃的对象会计数并写入审计横幅（“对象丢弃 N”），不再静默消失。

## 10. 协作

- **入口**：顶栏 `协作`；同机多标签需要在协作面板手动点击“启用本机同步”才会建立本地频道（默认不自动连接），跨设备可走 WebRTC 直连（邀请文本/二维码）。
- **能力**：对象增删改实时同步；场地编辑/清空实时同步（远端清空显示提示，可 Ctrl+Z 恢复）；楼层新增/删除/清空通过 `floor-add`/`floor-delete`/`floor-clear` 广播，接收端仍走同一套墓碑与 LWW 合并；断线期间改动写入本地待发队列（只保留最新一份整工程快照，上限 2 MB，超限或写盘失败会显式提示），恢复后先补发再同步；本机频道异常丢失按 1s→2s→…→5min 指数退避自动重连；按对象/楼层级 LWW，较新者胜出，删除有墓碑；图层/类型删除同样写墓碑并在合并中裁剪，内置类型与 `layer.default` 受保护；只有实际变化的对象会刷新 `updatedAt`（批量显隐/图层/对齐/重编号与节点增删均按变化 id 打点，无变化提交不产生新时间戳）。
- **M2 配置差异可见性**：合并仍本地优先；若远端有不同配置（`meta/settings/rules/titleBlock/layers/objectTypes`）未被采纳，或远端独有配置已补缺，会在协作状态栏/冲突提示/手动合并 toast 显示“配置未采纳 N 项 / 配置已补缺 N 项”。报告只增加可见性，**不代表远端配置已生效**；报告异常只降级，不阻断合并。
- **安全默认**：连接建立（`hello-ack`）后提示“对方拥有完整编辑权”（可覆盖对象、清空楼层/场地、改配置）；连接提示同时写明直连边界：仅限可直连网络（同一局域网/可直连）；跨 NAT 通常不可用（未配置 TURN）。跨设备 WebRTC 首次收到整工程快照时弹确认，拒绝即断开且不应用，同一连接只问一次；同机 BroadcastChannel 仍自动会合，不弹确认。两种连接都在接收端做 200ms 节流，只应用最新整工程快照。一次连接内远端最多写入一条撤销历史（只有首条真正覆盖本地内容时传 `{history:'overwrite'}`，之后传 `{history:false}`），不会冲掉本地 20 条撤销。上述行为由 selftest 39.13b 常驻断言覆盖。
- **限制**：底图与照片不走实时通道；WebRTC 没有信令通道，DataChannel 异常断开无法自动重连，只能重新交换邀请串（真实双设备未验证；39.13b 是 Node 桩，不等于真实 DataChannel 行为）；冲突统计已计入“纯冲突”，界面会显示“冲突 N 条（保留较新值）”，但只有真正覆盖本地内容才提供 Ctrl+Z 回滚；消息携带 `pid` 做跨工程隔离：业务消息必须双方都有 `pid` 且一致，草稿或空 `projectId` 不再跨工程放行（仅 `hello`/`hello-ack`/`bye` 控制消息兼容旧版无 `pid`）；草稿需先另存到工程库（绑定工程）才能参与实时协作，双方都未绑定工程时状态显示「已连接（未绑定工程，业务消息被忽略）」，不再只写「已连接」；同机编辑租约心跳要求字符串 tabId，对端时间戳被钳制到本机 `now−15s ~ now+5s`；协作合并会拒绝无法解析或超前本机 5s 以上的对象/墓碑时间戳（置空后由本地有效编辑胜出，并在合并信息栏显示异常条数）；协作在线表每 15s 发一次心跳，45s 无活动即移出并显示“已断开：心跳超时”；合并结果超对象上限时整批拒绝并保持现场；二维码编码上限 42 字节，超长请复制文本。

## 11. 版本快照

- **入口**：`工程库` 中每个工程行的版本入口；需先把工程保存/绑定到工程库。
- **能力**：生成命名快照；A/B 对比（对象按新增/删除/换楼层/类型变更/移动/属性修改分类；场景级差异追加场地形状、底图、楼层名、图层名与类型表结构，排在对象项之后）；回滚（回滚前把当前状态压入撤销栈，可再 Ctrl+Z；恢复前校验快照归属工程、schema 与当前打开工程一致，跨工程或缺版本记录被拒）；叠加查看（仅当前楼层，不进入渲染静态缓存与导出）。
- **存储**：列表与淘汰读取 `snapidx:<projectId>` 元数据索引，不再逐条反序列化快照 data；索引缺失（旧数据/损坏）时回退扫描并重建。工程与快照 id 在键中分别 URL 编码，命名空间仍是 `snap:<工程>:<快照>`。每工程 20 条 / 约 16 MB，按 UTF-8 字节淘汰最旧且至少保留 1 条；照片资产化只作用于快照副本，不改实时工程。资产库写入失败时**保留内嵌 base64 并提示“N 张设备照片未能存入资产库”**，不静默丢照片；此时快照体积会偏大。超过单张资产上限（16 MB）的照片无法入库，持久化副本不携带其 base64，只在当前会话可见，载入时以警告级提示告知。
- **限制**：每工程最多 20 条、总量约 16 MB（UTF-8 字节估算的软上限），超出淘汰最旧（单条超限仍保留）；对比列表最多展示 2000 条差异，超出部分不提供差异导出入口；差异已覆盖对象、场地/底图、楼层名、图层名与类型表结构，键顺序变化不再误报；旧快照缺少 `objectTypes` 时跳过类型表对比；真实图纸的误报率未验证。

### 11.1 图纸修订参照版

- **入口**：`设置 → 参照版`，选择另一个工程的 JSON 文件导入；参照版仅当前会话有效。
- **能力**：参照工程按对象 id 与当前工程比对，三类差异复用现有差异叠加：新增（绿）、删除（红虚线圈）、移动/改动（蓝）；参照对象按世界坐标半透明垫底，不透明度 10%～90% 可调；“闪烁”勾选后以 1 Hz 做 A/B 交替（当前工程 ↔ 参照版），关闭即停。
- **标定判定**：只比图片底图三要素——`metersPerPixel` 相对差 ≤0.1% 视为一致；相对差 >0.1% 或画布宽高不同、任一侧为仿射底图/缺底图时，判为“标定不一致 / 画布不一致”，在面板信息行与导入瞬间的 toast 里提示，**不自动缩放/平移、不猜测**。
- **数据边界**：参照版只作运行时状态（`rRef / rOp / rBl`），**不进 state、不进 JSON 持久化、不进协作、不进导出**，Schema 不动；关闭后释放，静态层签名回到无参照版的原值；切换/新建/导入工程时自动清空，不跨工程残留（同一工程内的撤销/重做、切楼层、快照回滚保留）。
- **限制**：只比对当前楼层；只覆盖图片底图三要素（场地质心/边界不参与判定）；来源本期只支持另一工程的 JSON（本工程快照来源按体积口径未接入）；闪烁固定 1 Hz，频率档位与 120 秒自动停已砍掉；参照版对象不响应图层可见性。

## 12. 插件

- **入口**：`设置 → 插件面板`；导入插件清单后立即交由用户确认加载，并写入本地插件库（独立 IndexedDB 键 `plugins:library`，不随工程保存）。**刷新后不会自动执行**：库内条目显示「已保存未启用」，须手动「启用」；启用前用 SHA-256 校验 id/版本/API 版本/能力/源码，任一被改即拒绝且不创建 Worker。库内最多 20 条，「卸载」可将条目移出本地库。
- **能力**：插件在独立后台线程中运行，通过消息调用声明过的能力（读取状态、添加对象/标注、导出器、规则等）；声明 API 版本，主版本不兼容或次版本高于宿主会被拒绝并给出原因；单次调用 2 s 超时后终止。
- **限制**：不是完整语言级沙箱。插件写入的对象与手动绘制共用撤销栈，Ctrl+Z 可完全移除、Ctrl+Shift+Z 可恢复。初始化完成后 Worker 会冻结并清除初始化期注册的 `setTimeout`/`setInterval`、删除全局定时器入口，插件无法在载入后继续改工程或长时间占用；冻结动作走微任务而非可取消的定时器 id，插件在载入期暴力 `clearTimeout` 也无法推迟冻结。**冻结只覆盖定时器**：Promise 微任务与同步计算仍可运行，插件在单次调用窗口内仍可能占用 CPU，实际约束是 2 s 超时与调用限流。Worker 内的 `fetch`/`indexedDB`/`WebSocket`/`localStorage` 等直连 API 已置空，`BroadcastChannel`/`MessageChannel`/`MessagePort` 与 `onmessage`/`onerror` 一并封堵。沙箱导出器未声明 `state:read` 时只会收到空 `input`（静态核对，运行期未覆盖）。插件清单与源码上限按 UTF-8 字节判定（192 KB / 64 KB），直调 `loadPlugin` 同样受限；清单原文超过 192 KB 时在 `JSON.parse` 之前即拒绝，循环引用清单返回明确原因而不抛异常；沙箱调用限流为 `getState` 60 次/分钟、`addObjects` 30 次/分钟、`addAnnotation` 60 次/分钟，超限只拒绝本次调用并返回原因，不禁用插件；下载只接受调用期内的 `callId` 且不超过 32 MB，越界即禁用并给出原因。插件注册的类型仍被对象引用时，卸载后保留定义；同一插件 id 重载可覆盖自身类型。注册/注销的自定义类型会写入当前工程类型表并进入自动保存与协作广播，刷新或重开工程后仍在（插件清单存于本地库，刷新后需手动启用）。只应加载可信来源的插件。

## 13. 几何规则检查

- **入口**：侧栏 `规则` 页签；`运行检查`、`导出 CSV`、`清空结果`。
- **能力**：三条内建规则——对象重叠（容差按重叠面积判定：交面积 ≤ 容差² 视为贴合）、最小间距（按类型配置阈值）、越界（完全/部分越界，含容差）；配置随工程持久化；违规清单可点击定位；可导出 CSV。
- **限制**：这是**几何检查，不是消防/规范审图**，不内置任何规范数值；未配置间距阈值的类型不参与间距检查，结果面板显示“未配置阈值类型 N 个”（不回退全局阈值、不静默跳过）；圆/椭圆按固定段数、凹多边形三角化近似；重叠检测遍历对象全部轮廓对取最大交面积；不做楼层间垂直关系；与 `统计` 页的基础问题检查口径不同。

## 14. 符号库

- **入口**：侧栏 `符号库` 页签；搜索、分类筛选、点击符号后放置。
- **能力**：内置约 36 个图元，分视频监控/门禁/消防/网络/停车/其他六类；可设放置旋转角与真实尺寸（0=屏幕固定图标）；自有符号支持 SVG 导入（安全清洗，仅识别 path/circle/rect/polygon/line/polyline）、按工程导入/导出 JSON。
- **一致渲染**：画布、SVG、PNG 使用同一矢量轮廓数据（canvas 与 SVG 是两套独立绘制实现，不做像素比对）；PDF 有两条路径——默认 `pdf` 的图纸页是位图（JPEG），由同一 canvas 渲染结果封装；另有一个显式选项 `pdf-vector`（底图/场地/网格为整页位图，对象轮廓与尺寸线为矢量，文字/点位图标/标题栏为透明位图，仍含清单页）。PNG/SVG/PDF 共用页脚“工程名 · 场地描述”；DXF 仅以折线近似并给出降级报告，图层表色取该层首个导出对象的颜色（最近 ACI），实体自身颜色不变。
- **限制**：DXF 不还原填充；SVG 只识别 6 类元素；符号 path 必须以 `M/m` 起始；搜索不支持拼音/分词；放置选项不持久化；新工程默认类型集由旧 64 图标收敛为 36 符号，旧工程靠自身类型表保留原图标。

## 15. 图框、标题栏、比例尺与图例

- **入口**：导出格式下拉选 `图框模板…`。
- **能力**：总开关默认关闭；启用后可画图框、右下标题栏（工程名/图号/比例/日期/版本/设计/审核/单位 8 字段）、左下比例尺、右上图例（按当前可见对象/图层聚合，最多 8 类/6 层，多余显示 +N）。配置随工程保存，旧工程缺失时按默认模板降级；文本统一清洗，超 80 字符截断。
- **限制**：只作用于 PNG/PDF/SVG；默认关闭以保证既有导出不变；不进入 CSV/XLSX/DXF。

## 16. 产品库与报价

- **入口**：导出下拉 `导出目录` / `删除目录` / `CSV 报价表` / `Excel 报价表`；属性面板填写厂商/型号/数量。
- **能力**：导入厂商目录 JSON 或 CSV（厂商/型号/单价，CSV 支持分类/单位可选列与千分位/货币符号清洗；含这三列的表会先询问是否导入为设备目录，取消则按对象表格导入），上限 2000 型号；按跨楼层汇总 BOM；有目录时计算单价与小计，无目录时降级为名称/数量；报价表沿用上次单价快照。

## 18. 移动端与离线

- **入口**：窄屏自动收起侧栏，顶栏 `☰ 面板` 切换。
- **能力**：响应式横竖屏、触控目标不小于 44 px、安全区适配、支持平移/缩放/捏合；离线缓存按版本命名，升级时清理旧版本并提示“新版本可用”。
- **两种离线形态**：源码多文件入口（http(s)）由 Service Worker 预缓存提供 PWA 安装与离线；单文件发行版 `dist/plotpin-standalone.html` **不含 Service Worker**，CSS/JS/图标全部内联，离线由文件自身保证，PWA 安装与预缓存只对源码入口成立。
- **file:// 下的 SW/PWA 是必然边界**：Service Worker 只允许 http(s) 脚本，`file://` 无法注册；产品按协议显式关闭（`detectCapabilities` 的 `sw=false`），不尝试注册、不报错。`file://` 下 IndexedDB、localStorage、下载与 CSP 内联哈希均正常。
- **限制**：通过 `file://` 双击打开可完全离线使用，但不支持安装与离线缓存；安装/离线需静态服务器或 HTTPS。真机 iOS/Android 安装、离线与手势未验证；低端设备渲染性能未测。

## 19. 安全与数据边界

- **已有防护**：HTML 输出统一转义；CSP 限制脚本来源；类型图标白名单；CSV/TSV/XLSX 公式注入防护；自有 SVG 导入清洗（禁脚本/事件/外链/超限元素）；资产按工程命名空间隔离；快照使用独立命名空间并以资产引用避免复制。
- **限制**：SVG 导出的对象颜色已按白名单归一（`#hex`/`rgb()/rgba()`/CSS 关键字，非法值回退默认色）；DXF 图层名已清洗 CR/LF/制表等控制字符并保证唯一（`SITE` 保留，重名加 `_2`）；符号 path 必须以 `M/m` 起始，`A/S/Q/T` 缺省当前点不再抛错；CSV 公式反转义会改写以 `'=` 开头的合法文本。

## 22. 带宽/存储估算（G3）

统计页「带宽/存储」按需弹窗：选编码格式、分辨率、帧率、码流类型，填路数、保留天数、每日写入小时与冗余开销，实时给出单路码率、总写入码率与保留容量。

- 码率口径：`单路码率(Mbps) = 基准码率(分辨率) × 编码系数 × 帧率/25 × 码流系数`。基准表与系数在 `js/features/io-fields.js`，均为**经验值**（H.264 1080p/25fps ≈ 4 Mbps；H.265 ≈ ×0.6；MJPEG ≈ ×4；子码流 ≈ ×0.3），可按实际设备改写，不是标准。
- 容量口径：`字节 = 码率 × 10^6 ÷ 8 × 3600 × 每日写入小时 × 天数 × 路数 × (1 + 冗余%)`，同时给出 **GB（10⁹ 字节）** 与 **GiB（2³⁰ 字节）**，报预算时须注明口径。
- 边界：0 天 = 0；空输入/超大值/负数先夹取到区间，不出现 NaN、Infinity 或负容量。
- 不承诺：不做真实码流抓包，不校验交换机背板带宽，不替代厂商计算器；子码流按同分辨率 30% 估算，属保守上限。上述边界以本文为准。
- 估算输入只在弹窗会话内，不写入工程、settings 或撤销栈；G3 不新增导出产物，工程导出链路零改动。

## 23. 布线/线缆统计（G4）

统计页「布线统计」按需弹窗：选统计模式、改端点预留与弯曲余量，实时给出明细、按图层汇总与合计。

- 长度来源：**沿走线路径**取折线首末顶点、沿折线逐段求和（闭合折线补首尾边），与画布 Σ 标注同源；**点对点直线**取点设备图元中心 `(x,y)`，按名称字典序相邻连接。明细按一条折线或一个相邻点对一行。
- 口径：`预留 = 端数 × 端点预留`（折线每条 2 端；设备链仅首尾 2 端）；`弯曲 = 几何长度 × 弯曲%`；`总计 = 几何 + 预留 + 弯曲`。端点预留默认 0.5 m/端、弯曲默认 10%，均为**工程经验值，可按实际改写**，不是标准。
- 取整：明细与合计按工程精度（默认 2 位小数）显示，内部按未取整值求和；按图层汇总只汇总**几何长度**，不摊派预留/弯曲。
- 边界：这是**几何估算，不是实测布线长度**；不自动避障、不识别线槽、**不含垂直段落**（安装高度不参与），不保证与现场一致，不能作为结算依据。
- 不承诺：不做线槽/桥架选型、不校验管径填充率、不替代工程量清单/造价软件；G4 不新增导出产物，工程导出链路零改动。

## 24. 本地只读（G5）

顶栏「只读」按钮切换本端写入锁：**这是防误操作的界面锁，不是访问控制，也不提供权限保护**。只锁本端编辑；协作对端仍可修改本工程，收到远端更新照常落盘与显示。

- 状态归属：运行时会话状态，不写入工程 JSON、不改 schema、不进协作消息、不持久化为工程属性；刷新后默认**可编辑**。
- 被禁（写入入口直接拒绝并提示原因，绕过 UI 的程序化调用同样拒绝）：新建（含测距/标注工具产生的尺寸对象）、拖拽/节点编辑、属性写入、删除、原地复制/粘贴、剪切、导入（JSON/DXF/PDF/图片/表格）、撤销/重做、清空楼层、批量操作（车位生成、批量属性/图层/旋转/删除）、规则应用与插件写入。
- 仍允许：查看与缩放、选择与搜索、读数型测量（尺寸/面积/长度只读计算，**不新建标注对象**）、导出、切换楼层、快照查看、只读协作；协作对端的远端变更旁路写入。
- 只读期间切到写工具会被拦回选择工具；被拒操作有可见 toast，撤销/重做按钮恒灰；本地只读不阻断协作连接，也不吞掉远端同步。
- 不承诺：不防止伪造的协作消息写入（无认证模型下任何"只读"都只是本端自律），不替代文件/工程级权限管理。

## 25. 评论/批注（G6）

侧栏「批注」页签管理**本机评论线程**：选中一个对象后输入文字添加，列表按更新时间倒序，可编辑、单条删除。

- 仅本机：评论**不随协作同步**，不进协作消息/合并，也不随 JSON 导出；UI 固定提示「评论不随协作同步，仅本机可见」。对端看不到，换设备也看不到。
- 存储归属：`localStorage['plotpin.comments.v1.<owner>']`，`owner = projectId || meta.id`；**不写入工程 JSON、不改 schema、不新增 IDB store**。工程库副本有独立 `projectId`，评论不串；草稿评论在另存为工程时迁移到 `projectId`。
- 锚点：`objectId + floorId`；对象被删除后评论保留为**孤儿**，列表标注「对象已删除」，可读/可改/可删，不提供定位入口（因此没有点不开的死链），也不静默删除用户文字。
- 不跟随：不做画布评论标记；对象移动/旋转/缩放不改变归属，本片**不做重定位**。
- 只读：可查看评论；新增/编辑/删除被 `guardWrite()` 直接拒绝，按钮同时禁用。
- 上限：单工程 200 条、单条 2,000 字；超长截断，空文本拒绝；存储不可用/配额满时明确报错，不谎报已保存。
- 删除路径：删除工程清该工程评论键；新建工程只清未入库草稿的评论；清空楼层不删评论（转孤儿）。

## 26. 台账模板导出（G7）

顶栏导出下拉的「台账模板导出…」是**显式选项**：只决定 CSV/XLSX 导出哪些列、列顺序与列标题；不选它时默认导出与旧版逐字节一致（N-26 golden 锁字节）。

- 模板是数据常量：`TPL_BUILTIN` 表（`{id,name,cols}`），`cols` 数组即列集合与列序；**不写入 state、工程 JSON、localStorage，不改 schema、不进协作、不随 JSON 导出**。
- 列标题 = `EXPORT_FIELD_DEFS` 的字段 key（同一来源，不另存标题副本），因此标题不会与字段表漂移。
- 内置模板「设备台账」「点位清单」是**只读常量，不可被用户覆盖**；弹窗里可临时改列（逗号分隔字段名），只作用于本次导出，不持久化。
- 列引用失效可见：保存与导出前都按字段表校验，未知列直接拒绝并提示「模板列不存在：{cols}」，不输出空列；已识别字段但对象无值（如点设备没有面积）输出空单元格，与默认导出口径一致。
- 报价边界：模板只作用于对象台账；单价/小计仍只走目录与报价快照（`quoteAggregate → quoteSnapshotTable`），不新增第二套计价。不承诺：不做税、不做多币种、不做合同条款。
