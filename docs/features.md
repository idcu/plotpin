# 图钉 PlotPin 功能说明

> 本文按**用户可感知的功能域**组织，不描述代码实现。行为以当前代码为准（核对于 `ebe0f85`，2026-11-08）。
> 已知缺陷与未验证项见 [known-issues.md](known-issues.md)；已下线功能见 [deletions.md](deletions.md)；操作步骤见 [user-guide.md](user-guide.md)。
> 文中的容量/精度上限取自程序内统一资源边界；此类数字会随代码调整，引用时请注明采集日期（2026-11-08）。产物体积、断言数、用例数、覆盖率、缓存版本号不在此硬编码。

## 1. 产品定位与适用边界

- 离线、免安装的图纸标注工具：底图校准、设备点位、真实比例区域/折线、尺寸标注、统计与导出。
- 数据保存在本机浏览器；无账号、无服务器、无网络请求。协作仅限本机多标签或局域网直连。
- 主要验证环境为 Chromium；Firefox / Safari 的导入、下载、沙箱与打印未验证（M2）。
- 明确的非目标：不做消防/规范审图，不做 CAD 全量编辑，不承诺无限容量，不做云端同步。

## 2. 画布与视图

- **入口**：主画布；顶栏 `−` / `适应` / `＋`；左下角缩放百分比与坐标读数。
- **能力**：滚轮缩放（约 2%–20000%）、适应窗口、右键/中键/空格拖拽平移、网格、十字准星、点图标显示大小滑杆。
- **绘制顺序固定**：图片底图 → 矢量场地 → 网格/覆盖率覆盖 → 场地标注 → 坐标轴 → 业务对象 → 选择/编辑手柄。取景框覆盖图片与场地的并集。
- **限制**：万级对象时缩放/平移依赖静态层缓存；单击选中可能触发静态层重建而卡顿（见 CORE-P1-5）。移动端真机手势未验证（M1）。

## 3. 对象、类型与编号

- **入口**：左侧工具栏 `选择` `平移` `点设备` `区域` `折线` `文字` `测距` `标注`；侧栏 `属性` `清单` `图层/类型` `统计`。
- **对象类型**：点设备；区域（矩形/圆形/椭圆/扇形/平行四边形，世界坐标真实比例）；折线（可闭合为区域）；文字；尺寸标注（两点距离/多点测距/面积/角度）。`测距` 工具只做临时测量，不落为对象；需要保留请用 `标注`。
- **编号**：自动编号形如 `O0001`，跨楼层查重；`清单` 支持批量重排（自定义前缀/起始/步长，自动跳过已占用编号）。矢量场地不占编号、不进清单/CSV。
- **编辑**：单击选择、框选、拖拽移动、拖节点、旋转/缩放手柄；`清单` 可改名称/坐标/参数/显隐/锁定，支持批量改图层、平移、旋转、删除、显示/隐藏标注。
- **类型与图层**：图层可新增/改名/显隐/锁定；类型可自定义类别、颜色、图标与物理尺寸图形（圆/方/扇形/杆）。每层共用图层与类型。
- **标注**：对象级标注含编号、坐标、基点、半径、边长、顶点、周长、面积、节点、段长；默认值沿用旧全局观感，可按对象覆盖。段长标注可设最小屏幕像素（默认 26 px，范围 10–60）。
- **限制**：楼层名必须唯一；新增/重命名重名会被拒绝，导入会因重名楼层整批拒绝。导入的对象标识/编号已在读入时去重（重复 id 追加 `_2` 后缀，重名对象走编号作用域），不再产生重复标识。
- **导出口径（N-05）**：CSV/TSV/XLSX 台账保留全量对象，「显示」列按**有效可见**（对象 `visible` 且所属图层 `visible`）标注，表头不变；PNG/SVG/DXF、PDF 图纸页与 PDF 清单只输出有效可见对象。草稿/校准属于交互瞬态，默认不进入 PNG/PDF 产物。

## 4. 校准与坐标

- **入口**：顶栏 `比例尺`（两点定标）、`仿射校准`（2 点=旋转+等比相似，≥3 点=最小二乘完整仿射）；左侧 `图片变换`（平移/旋转/等比缩放/切变，图片角点可吸附场地角）。
- **前置**：仅图片底图需要校准；矢量场地以自身坐标为基准。入口不可用时会禁用并显示原因（图片解码中、底图缺失、无图片底图等）。
- **场地优先**：存在矢量场地时，图片校准只改图片与业务对象，场地坐标不自动迁移；无场地时保持原行为。
- **限制**：2×3 仿射不提供四角自由拖拽（不能表达任意透视）；图片切变手柄在旋转 90° 附近会退化（CORE-P1-8）。
- **形状迁移（N-12）**：一般仿射（不等比/切变/旋转）下，圆与椭圆按精确主轴成像（正交共轭直径优先，否则 SVD），对象与场地共用同一实现；平行四边形按映射后的两条边向量重算宽/高/倾角/朝向。扇形仅在正向相似变换（旋转+等比缩放）下精确；其余情况按面积保真（半径 ×√|det|）近似并标记为降级（`sector-affine`），变换摘要的 `degraded` 会列出受影响对象。既有已校准坐标不做迁移，只对后续新应用的变换生效。

## 5. 双槽位：图片底图 + 矢量场地

- **入口**：顶栏 `底图/场地`；左侧 `场地节点`；`属性` 面板编辑场地参数。
- **槽位**：每层最多 1 张图片底图 + 1 个矢量场地，互不覆盖。场地支持矩形/圆形/椭圆/扇形/平行四边形/多边形。
- **场地能力**：拖节点改形；属性面板精确输入；场地标注（节点、段长、基点、半径、面积/周长）可逐项开关；场地参与捕捉；场地不参与选择/框选/对象计数。
- **渲染与导出**：画布、PNG、PDF、SVG、DXF 均输出场地；SVG 补齐节点/段长/半径/面积周长；DXF 输出到独立 `SITE` 图层；CSV/XLSX 不增加场地行。
- **兼容**：旧工程中类型为图片的底图原样保留且无场地；其它旧底图类型迁移为场地。可读取 v1/v2 工程；旧版应用对新增场地数据的忽略不在兼容承诺内。
- **扇形跨 0°**：起止角统一由 `sectorArcRange()` 归一为「起角 a0 → a0+有效张角」，画布、SVG、控制点共用；`350°→20°` 在屏幕与导出中都是 30°。场地编辑与清空进入撤销栈、自动保存并广播给协作方；远端清空场地会在状态栏提示且可 Ctrl+Z 恢复。

## 6. 测量、统计与分析

- **测距/标注**：逐点单击、双击结束；实时显示段长与累计总长；标注对象可保存并导出。
- **统计页签**：对象数量、面积、长度、楼层汇总，以及一组基础问题检查（尺寸过小、节点不足、自相交、超出场地等）。它是快速自检，不等同于 `规则` 页签的几何检查。
- **覆盖率分析**：顶栏 `覆盖率分析`；按固定目标格数（默认 18000，单次上限 200000，格边 0.03–10 m）估算可见区域覆盖率，高亮盲区，可导出盲区 GeoJSON。结果与视口缩放无关。
- **布点优化**：覆盖率结果弹窗内 `布点优化…`；输入视场半径/张角/目标覆盖率/最多新增台数，贪心给出新增点位，应用后自动重跑覆盖率。
- **停车规划**：顶栏 `停车规划`；按当前场地自动排布双面垂直车位与共用通道；默认车位 2.5×5.3 m、通道 6 m，通道净宽 <2.5 m 拒绝生成，<5.5 m 给出警告。
- **限制**：覆盖率是栅格估算，圆/椭圆/扇形按固定段数采样；v1 与 v2 数值不可比（K6）。统计页与规则页的越界容差口径不同，同一对象可能结论不同（RT-P2-14）。停车规划按“图片∪场地”取景框计算，图片大于场地时可能排到场地外（IO-P2-23）。

## 7. 文件导入

- **入口**：顶栏 `导入`；JSON/DXF/表格/图片也可拖到画布。支持 JSON、DXF、PDF、CSV、TSV、XLSX、图片。
- **JSON**：事务化替换当前工程；失败保持原现场。跨设备导入不接管本机工程库绑定。资产回收延后到 `afterStateLoaded()` 成功之后（N-11）：提交失败回滚时不会误删旧工程资产，成功导入后不可达旧资产正常回收。
- **DXF**：ASCII DXF 导入为点/线/圆/文字，可落到只读参考层；`.dwg` 不支持，需另存 ASCII DXF；R12 凸度当前按折线拉直。
- **PDF**：提取内嵌图作为图片底图，路径转折线/区域、文本转文字对象；多页按页序沿 +X 排布，不叠加，但只取一张内嵌图作底图，可能与矢量内容不同页（IO-P2-20）。含 `/cm` 变换的 PDF 曲线采样与文字定位已统一到设备空间（N-09）；文本字号仍按原始 `Tf` 值，缩放矩阵下的字号未同步放大。内嵌底图与图片导入走同一条内容寻址资产路径（`assetId` 入库，自动保存/重开后仍可取回）；解压上限在流式累计阶段生效，超过 64 MB 的 Flate 流与按像素尺寸估算明显超限的图像不会进入解压器。
- **图片**：作为图片底图导入；超 3000 px 长边会降采样，超大透明图可能转 JPEG。
- **限制**：单文件 32 MB、实体 10 万、表格 2 万行、对象总数 10 万；单对象顶点数没有上限，超大折线可能使包围盒计算抛错（CORE-P1-9）。

## 8. 表格布点与批量修改

- **入口**：`导入` 选择 CSV/TSV/XLSX；也可先导出同格式表格作为模板。
- **能力**：按表头映射编号/名称/对象类型/业务类型/楼层/坐标/尺寸/节点/图层/显隐/锁定/备注/型号等字段。存在 `操作` 列时进入严格模式：`新增`/`创建`/`更新`/`替换`；`替换` 可配合 `匹配编号`、`匹配名称`、`匹配名称包含`、`匹配对象类型`、`匹配业务类型`、`匹配图层` 条件批量改属性（不改几何）。无 `操作` 列时沿用旧自动路由（编号命中→更新，否则新增；带匹配列→替换）。
- **事务性**：严格模式出现非法行时整批不生效；预览可放弃。
- **限制**：所有单元格会去首尾空格；无法识别的布尔值可能被当作“否”；形状字段非法时该行几何（含 X/Y）会被丢弃；坐标按当前精度（默认 2 位小数）量化到厘米；工程存在重名楼层时整批拒绝（不再静默错层）；单工作表超过 5 万行会在解析阶段直接失败。

## 9. 多楼层、工程库与保存

- **入口**：顶栏 `新建` `工程库` `楼层` `清空`；右上角保存状态。
- **楼层**：每层独立图片底图、矢量场地与对象；图层/类型/工程名/标题栏等跨层共享。可新增、切换、重命名、删除；`清空` 清空当前楼层的底图、场地、对象与标注，可用 Ctrl+Z 撤销。
- **工程库**：把当前图纸另存为命名工程；打开/复制/删除本机工程；`合并他人工程…` 选择对方导出的 JSON 按对象更新时间合并。
- **保存**：修改后约 450 ms 自动保存草稿；绑定工程库后同步到工程库。撤销栈 20 步。存储不可用时降级并提示，应导出 JSON 备份。
- **限制**：楼层名唯一（新增/重命名重名被拒；旧工程重名加载只告警，导入整批拒绝）；删除图层/类型前检查全部楼层引用，有引用时确认后迁移到默认图层 / 同类内置类型；工程库快照见第 11 节。

## 10. 协作

- **入口**：顶栏 `协作`；同机多标签默认走浏览器本地频道，跨设备可走 WebRTC 直连（邀请文本/二维码）。
- **能力**：对象增删改实时同步；场地编辑/清空实时同步（远端清空显示提示，可 Ctrl+Z 恢复）；断线时可用 `工程库 → 合并他人工程` 做离线合并；按对象/楼层级 LWW，较新者胜出，删除有墓碑；只有实际变化的对象会刷新 `updatedAt`（批量显隐/图层/对齐/重编号与节点增删均按变化 id 打点，无变化提交不产生新时间戳）。
- **限制**：底图与照片不走实时通道；楼层新增/删除不广播（RT-P1-02）；断线期间改动不补发、断线后不自动重连（RT-P1-01）；冲突条数在“无变化”时可能不显示（RT-P1-03）；频道名可能沿用上一工程且消息无工程校验（RT-P1-04）；二维码编码上限 42 字节，超长请复制文本。真实双设备 WebRTC 未验证（M3）。

## 11. 版本快照

- **入口**：`工程库` 中每个工程行的版本入口；需先把工程保存/绑定到工程库。
- **能力**：生成命名快照；A/B 对比（按对象匹配分类新增/删除/换楼层/类型变更/移动/属性修改）；回滚（回滚前把当前状态压入撤销栈，可再 Ctrl+Z）；叠加查看（仅当前楼层，不进入渲染静态缓存与导出）。
- **限制**：每工程最多 20 条、总量约 16 MB，超出淘汰最旧（单条超限仍保留，属软上限）；差异只比较对象，场地/底图/图层/类型/楼层结构变化会显示“没有差异”（RT-P1-09）；真实图纸的误报率未验证（M8）。

## 12. 插件

- **入口**：`设置 → 插件面板`；导入插件清单，仅当前会话有效，不持久化。
- **能力**：插件在独立后台线程中运行，通过消息调用声明过的能力（读取状态、添加对象/标注、导出器、规则等）；声明 API 版本，主版本不兼容或次版本高于宿主会被拒绝并给出原因；单次调用 2 s 超时后终止。
- **限制**：不是完整语言级沙箱（K9）；插件写入的对象不在撤销栈（RT-P1-05）；初始化后的定时器/忙循环不受 2 s 限制（RT-P1-06）。Worker 内的 `fetch`/`indexedDB`/`WebSocket`/`localStorage` 等直连 API 已置空，`BroadcastChannel`/`MessageChannel`/`MessagePort` 与 `onmessage`/`onerror` 一并封堵（无法加入协作频道、无法旁路 token 校验）；端口通道不在插件契约内。只应加载可信来源的插件。

## 13. 几何规则检查

- **入口**：侧栏 `规则` 页签；`运行检查`、`导出 CSV`、`清空结果`。
- **能力**：三条内建规则——对象重叠（可设贴合容差）、最小间距（按类型配置阈值）、越界（完全/部分越界，含容差）；配置随工程持久化；违规清单可点击定位；可导出 CSV。
- **限制**：这是**几何检查，不是消防/规范审图**，不内置任何规范数值；未配置间距阈值的类型对不参与间距检查；圆/椭圆按固定段数、凹多边形三角化近似；不做楼层间垂直关系；与 `统计` 页的基础问题检查口径不同。

## 14. 符号库

- **入口**：侧栏 `符号库` 页签；搜索、分类筛选、点击符号后放置。
- **能力**：内置约 36 个图元，分视频监控/门禁/消防/网络/停车/其他六类；可设放置旋转角与真实尺寸（0=屏幕固定图标）；自有符号支持 SVG 导入（安全清洗，仅识别 path/circle/rect/polygon/line/polyline）、按工程导入/导出 JSON。
- **一致渲染**：画布、SVG、PNG、PDF 使用同一矢量轮廓数据；DXF 仅以折线近似并给出降级报告。
- **限制**：DXF 不还原填充；SVG 只识别 6 类元素；符号 path 必须以 `M/m` 起始；搜索不支持拼音/分词；放置选项不持久化；新工程默认类型集由旧 64 图标收敛为 36 符号，旧工程靠自身类型表保留原图标（K8）。

## 15. 图框、标题栏、比例尺与图例

- **入口**：导出格式下拉选 `图框模板…`。
- **能力**：总开关默认关闭；启用后可画图框、右下标题栏（工程名/图号/比例/日期/版本/设计/审核/单位 8 字段）、左下比例尺、右上图例（按当前可见对象/图层聚合，最多 8 类/6 层，多余显示 +N）。配置随工程保存，旧工程缺失时按默认模板降级；文本统一清洗，超 80 字符截断。
- **限制**：只作用于 PNG/PDF/SVG；默认关闭以保证既有导出不变；不进入 CSV/XLSX/DXF。

## 16. 产品库与报价

- **入口**：导出下拉 `导出目录` / `删除目录` / `CSV 报价表` / `Excel 报价表`；属性面板填写厂商/型号/数量。
- **能力**：导入厂商目录 JSON（厂商/型号/单价），上限 2000 型号；按跨楼层汇总 BOM；有目录时计算单价与小计，无目录时降级为名称/数量；报价表沿用上次单价快照。
- **限制**：目录导入事务化，非法目录不污染现有数据；同型号跨厂商重名且未填厂商时不计价；报价导出与台账共用公式注入防护。

## 17. 界面语言（i18n）

- **入口**：`设置 → 界面语言`（中文 / English）。
- **能力**：静态界面、动态面板文案与 ARIA 标签随语言切换；语言偏好保存在本机。中英覆盖率由门禁脚本统计，不以本文数字为准。
- **限制**：英文译文语义质量未经人工评审（M4）；系统生成的少量文案在英文界面下可能仍显示中文（CORE-P2-16）；外部数据（工程名、类型名、备注）不翻译。

## 18. 移动端与离线

- **入口**：窄屏自动收起侧栏，顶栏 `☰ 面板` 切换。
- **能力**：响应式横竖屏、触控目标不小于 44 px、安全区适配、支持平移/缩放/捏合；离线缓存按版本命名，升级时清理旧版本并提示“新版本可用”。
- **限制**：通过 `file://` 双击打开可完全离线使用，但不支持安装与离线缓存；安装/离线需静态服务器或 HTTPS。真机 iOS/Android 安装、离线与手势未验证（M1）；低端设备渲染性能未测（M5）。

## 19. 安全与数据边界

- **已有防护**：HTML 输出统一转义；CSP 限制脚本来源；类型图标白名单；CSV/TSV/XLSX 公式注入防护；自有 SVG 导入清洗（禁脚本/事件/外链/超限元素）；资产按工程命名空间隔离；快照使用独立命名空间并以资产引用避免复制。
- **限制**：SVG 导出的对象颜色已按白名单归一（`#hex`/`rgb()/rgba()`/CSS 关键字，非法值回退默认色，N-10）；DXF 图层名已清洗 CR/LF/制表等控制字符并保证唯一（`SITE` 保留，重名加 `_2`）；符号 path 必须以 `M/m` 起始，`A/S/Q/T` 缺省当前点不再抛错；CSV 公式反转义会改写以 `'=` 开头的合法文本（IO-P2-4）。
