# 特性清单（FEATURES）

> **这份文件是什么**：`README.md` 原「特性一览」全文 —— 29 条顶层特性（含 27 条子项，共 56 条），逐条写清了边界与实现口径。
> **为什么单独成文**：这一节占 README 一半篇幅，而 README 的读者要先看到"这是什么、怎么上手"；
> 细节留给需要细节的人（选型、验收、二次开发）。
> **内容只搬运、不改写**；一句话概览见 [README](../README.md)。

- **零依赖离线运行**：无 npm、无 CDN、无后端，`index.html` 双击即用；可在内网、涉密、现场无网络环境使用。第三方能力以 `@idcu/*` 公共模块随 `ngm.vendor` 分发，公共模块版本以项目根 `ngm.lock` 为准，所需 `ngm` 版本见 `.ngm-version`；`node scripts/check-ngm.mjs` 做 vendor/清单/锁一致性自检。CI 的 `ngm verify --deep` job 使用仓库变量 `NGM_BIN_URL` 与 `NGM_BIN_SHA256`，未配置时该 job 跳过、vendor-check 仍运行。
- **产品边界**：plotpin 是独立产品，只消费 `gitee.com/idcu/ngm-repo` 的 `@idcu/*` 模块；不得 import `payroll-server` / `qforge`，也不读取它们的数据库/API。
- **双槽底图（图片栅格 + 矢量场地共存）**
  - 每层最多 **1 张图片底图 + 1 个矢量场地**，两个槽位独立保存、互不覆盖；同一层可以「影像打底 + 红线定界」。
  - 图片底图（PNG/JPG/WebP/BMP/GIF/SVG）：两点定距完成**米/像素比例尺校准**；校准点落点后可拖拽调整、`Delete` 删除选中点、`Ctrl+Z` 撤销，按 `Enter` 或左侧 ✓ 才提交换算；导入/替换图片不会删除已有矢量场地。比例尺/仿射提交统一走 `applyWorldTransform`：对象（坐标、设备物理尺寸、文字字高、线宽、圆/椭圆/扇形参数）与图片仿射一次迁移，**已仿射校准的底图二次改比例尺不会再错位**；矢量场地按「场地优先校准」保持真值参考不自动迁移。
  - 图片整体变换（左侧「**🖼 图片变换**」工具）：橙色中心手柄=平移、蓝色圆点=旋转、右下角=**等比缩放**、顶边中点=**切变**；只做这四类整体变换，**不提供四角自由拖拽**，避免底图被拉成任意四边形。变换只改图片自身，不移动任何标注对象；平移/缩放时图片角点靠近**场地边角**会自动吸附对齐。
  - 矢量场地（独立 `state.site`，不进对象列表、不占 O 编号与 CSV/XLSX 行）：直接以米为世界坐标绘制**矩形 / 圆形 / 椭圆 / 扇形 / 平行四边形 / 多边形**场地，无需校准；替换场地不会删除图片底图。**椭圆数值输入只填长/短轴半径（中心固定世界原点）**，亦可拖拽绘制。场地边角同时作为**端点捕捉候选**：绘制/移动业务对象靠近场地角点时会自动吸附。
  - 取景框取 **图片四角框 ∪ 场地实际包围盒**；渲染顺序固定为「图片 → 场地 → 网格/覆盖 → 场地标注 → 业务对象 → 工具手柄」，场地始终压在图片之上。
  - 场地优先校准：**存在场地时，图片校准只改图片与业务对象，场地坐标永不自动迁移**；无场地时保持旧的「对象随底图比例尺缩放」行为。
  - 旧工程自动迁移：旧档 `background.kind==='image'` 原样保留且 `site=null`；其他类型旧底图整体迁入 `site`，图片槽置空。顶层与每个楼层都迁移，迁移过程不丢数据。**存储格式 v1 → v2**：读取旧档时自动升级，为每个楼层补 `updatedAt`（旧档缺失值保留空串，不会被误判为最新写入），下次保存写回 v2。
  - **旧版兼容限制**：旧版 App 既不认识 `site`（打开会忽略并丢弃场地），也**只认 schema v1**——遇到 v2 工程会拒绝加载/导入；本项目不做双写兜底，跨版本协作时请统一升级。
  - 矢量场地可在图上叠加**场地标注**：边界节点世界坐标、相邻节点**段长**、基点/圆心坐标、半径、中心**面积**与**周长**；六项开关已从「工程设置」搬进**场地属性面板**（固定字号不随缩放变化），矩形与多边形按真实边界逐点标注。开关值仍存 `state.settings` 原键（`siteNodes / siteSegLen / siteBase / siteRadius / siteArea / sitePerimeter`），旧工程读取不受影响。
  - 场地绘制完成后可继续微调：左侧「**⊗ 场地节点**」工具在画布上显示各控制点，拖拽即改形状（多边形顶点 / 矩形与平行四边形四角 / 圆心与半径 / 椭圆两轴与旋转 / 扇形两边与张角 / 平行四边形倾角）；属性面板同步提供**坐标与参数精确输入**，多边形支持顶点增删与 ↑↓ 排序、画布双击边插点 / 双击顶点删点。场地的显示/锁定与图层语义一致：所属图层隐藏则场地不渲染、不计入取景框，所属图层锁定则场地控制点不可拖拽；多边形顶点编辑与折线/闭合区域共用同一套节点编辑器。
  - 导出：JSON 同时保存图片与场地；PNG/PDF 按同一渲染顺序（含场地标注，按导出画布尺寸定位）；SVG 同时输出两层并带场地节点/段长/半径/面积周长标注；DXF 将场地写入独立 `SITE` 图层 `LWPOLYLINE`；CSV/XLSX **不含场地行**。
- **点设备（位置语义）**：内置通用标记、摄像头、球机、路灯、道闸、充电桩、警示点等图标；图标为**屏幕固定大小**，缩放画布时始终清晰可点。
  - 图标大小三层可调：**全局倍率 × 类型默认大小 × 单个对象覆盖**，底图再大也能让点位醒目。
  - 高级选项：设置物理尺寸（米）后可按真实比例渲染覆盖范围（圆形覆盖、方形区域、摄像头扇形视场、道闸杆）。
- **区域 / 折线（几何语义）**：统一按世界坐标（米）绘制，缩放时与底图保持真实比例。
  - 区域支持**矩形、圆形、椭圆、扇形（饼形）、平行四边形**参数化形状，属性面板可随时**互换形状**（中心不动、等面积换算）；三角形与任意多边形由闭合折线完成。平行四边形按「底边 × 高 + 倾角」定义，**错切不改变面积**，画布上提供专用的倾角手柄（横向拖拽面积恒定）；倾角限 ±80°。
  - 每种形状带专用控制点（角点 / 半径端 / 两轴端 / 扇形两边端与弧中点），并可直接设置**基点 / 圆心**坐标。
  - 线段 / 折线逐点录入，可闭合；实时长度、周长、面积统计；节点支持面板精确改坐标、插入、删除、↑↓/拖拽排序，画布双击线段即可插点。
  - **逐对象「图上标注」开关**：点设备（编号 / 点坐标）、区域（编号 / 基点坐标 / 半径 / 边长 / 顶点坐标 / 周长 / 面积）、折线（编号 / 节点或顶点坐标 / 段长 / 周长 / 面积）均在**各自属性面板**内单独勾选。工程设置与顶部工具栏的全局「显示标签 / 段长度标注 / 图上显示面积」入口已移除，避免同一开关出现两处；`state.settings.showLabels / showSegLen / showAreaTag` 仍作为旧工程与未单独配置对象的缺省值保留（不改 schema、不做迁移）。画布与 SVG 导出同步生效。
  - 区域与闭合折线可在图形中心**常驻显示面积/周长标签**（固定字号不随缩放变化，按对象属性面板的「面积 / 周长」开关关闭；闭合折线绘制过程中实时预览）。
- **标注与文字**：左侧工具栏独立的 **📏 测距**工具（百度地图式：逐点单击、**双击结束、右键/Esc 取消**，双击不产生重复节点；实时显示每段长度+累计总长，节点可编辑）；另有两点距离、折线 / 多边形面积、三点角度标注；文字按世界字高放置、可旋转。
- **编辑能力**：点选 / 框选 / 多选（Shift 或 Ctrl/Meta 点击增量选择）、移动、缩放、旋转、节点编辑、复制粘贴、图层显隐锁定、类型管理、网格吸附、撤销重做；**单击对象仅选中，不触发保存、不清除覆盖率叠加层**，拖拽未产生实际位移（<2px 或拖回原位）同样不落盘、不留空撤销快照；方向键连按/长按合并为一次撤销；多选后可按包围盒**对齐**（左 / 水平居中 / 右 / 上 / 垂直居中 / 下）与**等间距分布**（水平 / 垂直），保持首末对象不动，可撤销；支持按前缀/起始/步长**批量重排编号**（自动避让全工程已有编号）与**置顶/置底**层级调整。撤销栈保留 20 条、`Ctrl+Z / Ctrl+Y` 语义不变，但改为**结构共享快照**：未变对象子树与照片 base64 字符串按引用复用，1000 对象 + 10 张照片的 20 条历史实测堆增量 **28.26MB → 1.03MB（-96.4%）**，单次撤销 **4.0–18.5ms**（真实 Chromium，3 轮采样）。
- **精确绘图辅助（均可开关）**：**对象捕捉（OSNAP）**——端点□、中点△、圆心◎、象限点◇、垂足⊥、跨对象交点×、圆切点，按类型优先级自动吸附（画线、放设备、拖节点/角点均生效，可在设置关闭）；**Tab / Shift+Tab 循环锁定单一捕捉类型**（自动→端点→中点→圆心→象限点→交点→垂足→切点，底部徽标实时显示，点击徽标恢复自动）；画线时沿 45° 极轴或与上一段平行方向显示**橙色追踪虚线**；鼠标**十字准星 + 吸附后世界坐标**实时跟随（无需点击，鼠标一移动即更新，坐标栏同步显示当前捕捉类型）；折线绘制中/选中后显示**每段长度与累计总长**；区域拖画实时显示宽×高/半径；按住 **Shift** 画水平/垂直线（正交）、拖正方形/正圆、扇形 45° 方位吸附；属性面板编辑节点坐标时画布同步高亮；`F` 一键适应窗口；**段长标注最小屏幕像素可调**（设置项 10–60px，默认 26px，短段自动略标避免拥挤）。
- **几何检查**：零尺寸、折线自相交、对象越界、物理尺寸异常等自动提示。**规则页签（C-05）**提供可注册的规则框架与单次检查：三条内建规则——对象重叠（同楼层包围盒穿透 > 容差才做多边形交面积判定，贴边与容差内浅穿透不报）、最小间距（只比较已配置阈值的类型两两，两对象阈值取 max，净距 **小于** 阈值才报，恰好达标不报）、越界（以矢量场地边界为准，区分「部分越出」与「完全越出」，文字/尺寸标注/点设备同样参与）；违规清单含规则名/对象编号/名称/关联对象/楼层/X·Y/说明/实测值，点击行可跨楼层定位并选中主/关联对象，可导出 CSV（BOM + 引号/公式注入防护）。配置 `state.rules` 随工程保存、载入时归一、协作合并本地优先。**页面明确提示这是几何检查，不是消防/规范审图，不内置任何规范数值**；阈值全部由用户填写。2000 对象 / 30 类型阈值实测检查耗时 **14.3–15.2ms**（5 次中位数 14.3ms，CI 复跑 15.2ms；minX 扫描线候选对 7 / 理论 2,221,111；同场景全量两两对照 15,666.4ms，加速约 1096×）。已知限制：圆/椭圆/扇形按 72 段采样、凹多边形三角化近似，边界误差在采样/三角化容差内。
- **视场覆盖率分析**：一键统计摄像头（扇形视场）/球机与圆形、方形点设备的视场对**区域与闭合折线**的覆盖率；画布叠加显示**已覆盖（绿）/ 盲区（红）**栅格，弹窗给出逐区域与合计的覆盖面积、盲区面积与覆盖百分比（栅格法估算，零依赖）。统计口径 **v2**：固定目标 18000 格按**可见区域面积**分配，格边 0.03–10m、总格数 20 万上限，**与视口缩放/画布像素/DPR 无关**（同一图纸 4 个缩放级别实测差异 0.00pp）；隐藏对象与隐藏图层不计入分母，恢复可见后结果可复现。报告显式标注镜头口径：张角取类型 `fov`（默认 90°，10–360°，360° 视为全向）、有效距离取点设备 `phys`（m），扇形半径 = phys、圆/方 = phys/2，未填 `phys` 的图标点不计入。结果一次性写入 ImageData 后整块绘制；**盲区可导出为 GeoJSON 多边形**（逐行合并的矩形面，便于 GIS/CAD 复核）。**历史 v1 报告格数随缩放自适应，数值不可直接对比**。
- **性能与工程化**：画布采用**分层离屏缓存**——底图/网格/未选中对象冻结为静态层，拖拽时只重绘选中对象与交互层；配合**视口裁剪**。真实 Chromium 基线（`npm run perf:browser`，1920×1080/DPR1、全视野最坏情况）实测：2000 / 5000 / 10000 对象的缓存帧 P95 为 **1.3–6.4ms**，静态层重建 P95 为 **39–297ms**，heap 峰值 **16–79MB**；DPR2 下静态层位图 5.77→23.09MB、缓存帧 P95 11.8–18.4ms。`node scripts/bench.mjs` 提供 Node 桩阻断门禁（进 `npm run ci`），真实浏览器数据另有一套可选门禁，两者口径与数据**不得混用**（见 `docs/engineering.md` §5.4）。对象编号走批量作用域（`objectNameScopeFor / withObjectNameScope`）：10000 对象 JSON 空工程导入约 **0.28–0.38s**，当前工程已有同规模对象时导入约 **0.31–0.38s**（修复前约 4.1–4.8s 的 O(N²) 已消除）。导出的 SVG 与 DXF 顶点统一取自 `outlineOf`（区域/折线/标注同源），场地尺寸统一取自 `siteBounds`，第三方模块缺失时由 `ensureVendor` 给出中文错误。测试补齐**SVG 视觉快照哈希**（复杂场景导出回归）与**真实 DOM 语义桩**（弹窗初始焦点 / Tab 首尾循环 / Esc 焦点还原），保持零依赖。工程自带门禁：`node scripts/check.mjs` 校验语法、入口资源完整性、离线引用与断言数一致，`node scripts/badge.mjs` 自动同步 README 徽章，CI 配置见 `.github/workflows/ci.yml`。
- **布点优化**：基于覆盖率栅格的**贪心覆盖最大化**——枚举候选位置与朝向，逐台给出「新增覆盖面积 / 累计覆盖率」，可设定目标覆盖率与最多新增台数；一键应用建议并自动重跑分析，形成闭环。规划网格使用与报告同源的**固定格数口径**（不随缩放变化；为控制候选枚举耗时取较低目标格数），镜头参数与报告一致。
- **停车规划**：按当前场地范围自动排布**双面垂直车位 + 两侧共用通道**，支持横/纵排列、车位宽深/通道宽/边距参数与实时预览；内置**通道净宽与车位尺寸规范检查**（<2.5m 拒绝生成，<5m 提示），生成到独立「停车场」图层并记录删除墓碑，可撤销。
- **设备台账深化**：型号 / 安装高度 / IP / 责任人字段随 CSV/XLSX 双向无损往返；点设备可附加**现场照片**（内容寻址资产库、JSON 内嵌可移植）；可导出**可打印二维码标签**（扫码得到 `PLOTPIN:编号`，工程内搜索编号即可定位），二维码编码器零依赖且与标准实现逐模块一致。
- **多楼层 / 多底图**：顶栏「🏢 楼层」管理每层独立底图与对象，支持新增/切换/重命名/删除，楼层共用图层与类型；顶栏「清空」可一次性清空**当前楼层**的图片底图、矢量场地、全部业务对象与标注、校准控制点/仿射、选中态，并把取景框恢复默认；操作前二次确认，先 `pushHistory` 因此可用 `Ctrl+Z` 整体撤销（楼层结构、图层与自定义类型不受影响）。保存、JSON 导出与资产回收均覆盖全部楼层；**资产回收按命名空间取可达集**（草稿 + 撤销/重做栈每一帧 + 剪贴板 + 拖拽原件 + 自动保存草稿 + 工程库每个 `proj:<id>` 记录 + 版本快照 `snap:<pid>:*`），并集之外才删除——打开/新建/删除任一工程都不会误删其他工程的底图与照片。统计页签提供**按楼层汇总**（对象数/分类/总长/总面积，点击楼层行即切换）；打印报告与 PDF 导出在多层工程中**逐层输出图纸页与对象清单**（封面附楼层汇总），完成后自动恢复原楼层、视口与选择集；台账 **CSV/XLSX 导出覆盖全部楼层并带楼层列**，导入按楼层列路由（未知楼层或跨层重复编号会告警并跳过）。

  - **设备产品库与 BOM 报价**：导出下拉「导出目录 / 删除目录」管理厂商目录 JSON（`plotpin-catalog/v1`：`vendor / model / category? / unit? / price / params?`），目录存 IndexedDB `catalog:current`，导入**事务化**（校验 → 落盘 → 才替换内存，失败不覆盖现有目录）。属性面板「厂商」「型号」均可从目录下拉选型并填写「数量」；只填型号且该型号在目录中唯一时自动绑定厂商/单价，**跨厂商重名不自动绑定**，未填厂商时面板给出提示、报价行单价留空并在导出时提示。报价按**厂商+型号跨楼层**聚合（数量 × 单价 = 小计，末行合计），CSV/XLSX 共用同一字段表与 `guardFormula` 公式防护。导出时记录**目录版本（内容指纹）与导出时间**（合计行末两列），并把该次报价行写入 IndexedDB `quote:last` 快照：行集合（厂商/型号/数量）不变时**重导沿用冻结单价**，替换目录不会改写已定稿报价；数量或型号变化才按当前目录重新计价。未载入目录时降级为「名称、数量」两列，不臆造金额。
  - 台账列覆盖完整几何：**基点 X/Y、形状（矩形/圆/椭圆/扇形及扇形起止角）、闭合标志、各节点坐标（`x,y;x,y;…`）、标注类型（测距/距离/面积/角度）**——折线、闭合区域、测距链均可由表格无损重建；仅改基点列时整条线按基点平移。
  - 导入逐行核对：**长度/面积/节点数按几何重算比对**（含坐标取整传播误差界，避免误报），手改不一致或负值在预览中告警、不阻断导入、一律以图形几何为准；旧版表头与缺列自动跳过核对。
  - **DXF 实体与版本兼容（B-03）**：读取 `$ACADVER` 与 `$INSUNITS`，覆盖 R12 / R13 / R14 / 2000 / 2004 / 2007 / 2010 / 2013 / 2018 的 ASCII DXF；除公共模块已有的线/多段线/圆/弧/点/文字/块参照外，补充解析 `SOLID`、`3DFACE`、`LEADER`、`ATTRIB`/`ATTDEF`（前两者按闭合区域、LEADER 按开放折线、属性文字按文字对象落位，坐标同样按 INSUNITS 换算）。二进制 DXF 会明确提示「另存为 ASCII DXF」，不再落入泛化的「不支持的文件类型」。导入结果会如实列出：文件版本、补充解析实体、被跳过的暂不支持类型（如 DIMENSION / HATCH），以及 R12 `POLYLINE` 凸度（VERTEX 42）会被拉直的提示。
  - **DXF 预检 / 单位确认 / 双落点（B-02）**：DXF 导入先弹出**预检**（版本、`$INSUNITS`、可导入实体数、块定义、补充解析与暂不支持类型），用户可**确认或改判单位**（按文件 / 毫米 / 厘米 / 米 / 英寸 / 英尺，改判后几何整体换算），再选择落点：**可编辑对象**（按原图层，缺层自动建开放层）或**只读参考层**（新建 `DXF参考 · 文件名 · 版本` 图层并**默认锁定**，整层不可编辑）。确认后才事务化提交：导入期间失败（异常/超限）会恢复导入前快照并撤销该条历史，不留半导入对象。
  - **DWG 兼容入口（B-02）**：选中 `.dwg` 时读取文件头 `AC10xx` 并显示对应版本（R12 / R13 / R14 / 2000 / 2004 / 2007 / 2010 / 2013 / 2018），给出「转 DXF / 转 PDF / 取消」指引并可直接选择本机转换后的文件；**不内置 DWG 内核、不使用 ODA/Aspose 授权、不修改原文件**，单文件承诺不变。动态块 / 外部参照 / 代理对象 / 标注样式在转换时可能丢失，导入后以保真度提示为准。
  - **表格批量布点与条件批量替换（B-08 原义）**：表头可加「操作」（新增 / 更新 / 替换）与「匹配编号 / 匹配名称 / 匹配名称包含 / 匹配对象类型 / 匹配业务类型 / 匹配图层」列。新增行按 X/Y（折线/标注按节点坐标）批量落点，沿用统一编号作用域；更新按编号；替换行对**同时满足全部匹配条件**的对象批量改写名称、业务类型、图层、型号、安装高度、IP、责任人、备注、显隐与锁定（不改几何）。存在「操作」列时为**严格模式**：任一行非法（未知编号 / 未知业务类型 / 未知图层 / 非法台账值 / 替换缺条件 / 新增编号重复）整批拒绝，预览不提供「合并导入」，现有对象不被修改；批量应用另有快照回滚兜底。导入仍受文件体积、行数、对象数上限约束；导出时加在公式文本前的单引号会在导入时自动还原，保证「导出 → 再导入」文本不变形。
