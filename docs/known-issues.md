# 遗留项归档（Known Issues）

> Phase A / B / C 以来的「未验证 / 未完成 / 风险」统一收口于此。
> 分三类：**可自动化验证**（有明确判据可补进 CI）、**需人工或真机验证**（离线 CI 无法复现）、
> **已知限制不修**（产品/技术边界，明确不承诺）。
> 每条注明来源任务、当前影响、验证方式或保留理由；新增遗留项只能追加，已关闭项标注「已关闭」并保留记录。
> 相关门禁与阈值见 [engineering.md](engineering.md)；特性边界见 [features.md](features.md)。

## 3. 已知限制不修（明确不承诺）

| # | 来源 | 事项 | 当前影响 / 保留理由 |
|---|---|---|---|
| K1 | B-15 | Service Worker 的 `CACHE` 版本号**无自动门禁** | 预缓存清单运行时解析，构建期不知道「上一版」；靠发布纪律 + `pwa.test.mjs` 守下限 |
| K2 | B-11 | 通用 `measureText` LRU、通用 Path2D 缓存、图层/对象索引、`staticKey` 精确化不引入 | A/B 实测收益低于运行噪声；**C-04 例外**：仅符号路径按类型做 `WeakMap` 窄缓存（缓存帧 0.08–0.10ms / 500 图元） |
| K3 | B-13 | PDF 导出为**位图页**，回读不能还原矢量坐标 | 零依赖 PDF 写库不实现矢量对象；多页布局已修正，坐标精度仍受限 |
| K4 | B-02 / B-03 | `.dwg` 不支持；DXF 二进制需另存 ASCII；R12 凸度可能丢失 | 自研解析器只覆盖 ASCII DXF 常用实体；页面明确提示转换路径，不静默丢数据 |
| K5 | B-06 | 二维码编码上限 **42 字节**，超限只提示不渲染 | 邀请串超长时二维码不可用，保留文本复制路径 |
| K6 | B-09 / A-11 | 覆盖率 v1/v2 数值不可比；圆/椭圆/扇形按 **72 段**采样；栅格法估算 | 精度与性能的取舍，报告与文档已标注口径 |
| K7 | C-05 | 规则检查是**几何检查**，不是消防/规范审图；不内置规范数值 | 不判断消防间距/疏散/结构/日照；圆/椭圆 72 段、凹多边形三角化近似；不检查楼层间垂直关系 |
| K8 | C-04 | 符号 DXF 只做折线近似不还原填充；SVG 导入只识别 6 类元素；搜索无拼音/分词；`symbolPlace` 不持久化；新工程默认类型集 64→36 | DXF 格式能力边界；导入白名单是安全取舍；检索保持零依赖；放置选项是临时交互态；旧工程靠 `objectTypes` 保留原图标 |
| K9 | C-01 | 插件 Worker 是**隔离边界**而非完整语言级沙箱，无 CPU/内存配额 | 插件仍可访问 Worker 全局（`console`/`Blob`/`crypto`），只靠 2s 超时 terminate |
| K10 | B-06 | 协作仅 **LWW** 合并、无服务端、无冲突解决 UI | 定位为局域网/同机轻协作；跨设备可靠同步不在承诺范围 |
| K11 | 收口 | `docs/engineering.md` 超过 discipline 第 11 问自设的 60 KB / 600 行上限 | discipline 当前 **12/13（L3）**；缺口 C-04 前已存在（HEAD~1 为 63.8 KB / 664 行，按纪律脚本 KiB 口径；修正后 69.9 KB / 714 行），本轮不重构文档 |
| K12 | A-13 | 导入文件 32MB、对象 10 万、历史 20 条、墓碑 2 万、快照 20 条/16MB 等硬上限 | 防内存与卡顿的设计边界，超限明确报错/淘汰，不承诺无限容量 |
