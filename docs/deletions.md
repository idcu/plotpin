### 2026-11-08 · 移除全局“图上标注”总开关入口

- 删除：顶栏与工程设置中的“显示标签 / 段长度标注 / 图上显示面积”全局入口（三个复选框），以及由此产生的全局开关交互。
- 日期：2026-11-08
- 批准：仓库维护者（文档重写授权范围内核对）
- 为什么：全局开关与对象级标注重复，且无法表达“某些对象例外”；用户反馈入口分散、容易误以为对象属性丢失。
- 替代方案：改为对象级标注三态“默认 / 显示 / 隐藏”，默认值沿用原全局观感；段长标注最小屏幕像素仍可全局设置。
- 对旧工程/旧数据影响：旧工程中的原设置键仍被读取为对象默认值，不丢配置、不改结构；旧工程打开后观感保持一致。新工程不再有全局入口。
- 验证：属性面板标注分组；旧工程夹具打开后标注默认值不变；三级门禁与导出基线未回退。

### 2026-11-08 · 内置图标集由 64 个收敛为 36 个符号

- 删除：新工程默认类型表中的 64 个内置图标定义（被符号库的 36 个图元取代）。
- 日期：2026-11-08
- 批准：仓库维护者（C-04 符号库任务既定取舍）
- 为什么：64 图标与符号库功能重复，且路径数据体积大，挤压单文件产物上限。
- 替代方案：内置 36 个符号（视频监控/门禁/消防/网络/停车/其他六类），支持搜索、旋转、真实尺寸与自有 SVG 导入。
- 对旧工程/旧数据影响：旧工程自带类型表，打开后仍使用原图标，不迁移、不改类型标识；缺类型表的旧 JSON 会得到 36 个默认符号，外观可能与旧文档截图不同。新工程默认类型集为 36。
- 验证：旧格式夹具与 SVG/DXF 导出基线（A1/A6）；符号路径在画布、SVG、PNG、PDF 同源，DXF 折线近似并有降级说明。

### 2026-11-08 · 覆盖率 v1 自适应格数口径下线

- 删除：按视口缩放推导目标格数的 v1 覆盖率统计口径。
- 日期：2026-11-08
- 批准：仓库维护者（覆盖率口径变更既定决策）
- 为什么：同一图纸在不同缩放下得到不同覆盖率，无法复现、无法比较、无法做性能门禁。
- 替代方案：v2 固定目标格数（默认 18000，单次上限 200000，格边 0.03–10 m），按场地多边形面积分配格数，隐藏图层/不可见区域不计入。
- 对旧工程/旧数据影响：不迁移历史覆盖率结果（结果原本不持久化）；旧报告/旧截图中的百分比不可与新结果直接比较，引用时必须标注 v1/v2 口径。
- 验证：覆盖率正反例与性能断言（K6）；5000×5000 m 场地单次分析性能门禁；导出盲区 GeoJSON 与报告口径说明。
