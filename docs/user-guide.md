# 用户手册（user-guide）

> **读者**：最终用户与实施人员。
> **回答**：每项任务怎么操作、预期看到什么、常见坑在哪。
> **不回答**：功能承诺与限制的完整口径见 [features](features.md)，实现见 [ARCHITECTURE](ARCHITECTURE.md)。
> **口径**：按当前代码核对，2026-11-13（基线 `2123a46` + M1/M2 修复）。容量等易变数字见 [facts](facts.md)。
> **浏览器边界**：桌面 Chromium 系（Chrome/Edge）是唯一有自动化证据的入口；Firefox/Safari 未验证，见 [testing](testing.md)§3。

## 1. 打开与安装

- **直接使用**：双击发行包 HTML，或在静态服务器/HTTPS 地址打开。首次使用无需账号与网络。
- **安装/离线**：必须通过 `http://` 或 `https://` 打开，浏览器菜单选「安装应用/添加到主屏幕」；`file://` 下可绘图导出，但不能安装、不能启用离线缓存。
- **数据位置**：草稿、工程库、快照保存在本机浏览器；隐私模式、禁用存储、清理站点数据都会丢失，重要图纸请导出 JSON。
- **常见坑**：手机通过局域网 IP 访问不是安全上下文，不能验收 PWA；需 HTTPS 部署。

## 2. 首次启动与界面

- **首次启动**：本机无有效工程时提示新建或载入示例；示例不含图片资产。
- **顶栏**：新建、工程库、楼层、导入、导出、打印、底图/场地、比例尺、仿射校准、覆盖率分析、停车规划、协作、面板、设置、清空、撤销/重做、缩放/适应。
- **左侧工具栏**：选择、平移、点设备、区域、折线、文字、测距、标注。
- **右侧页签**：属性、清单、图层/类型、符号库、统计、规则。
- **要点**：不导入底图也能先画矢量场地并布点。

## 3. 新建、保存与工程库

### 3.1 新建与自动保存

- 顶栏 `新建` → 输入工程名（可留空）。修改后约 450 ms 自动保存草稿，右上角显示保存状态。
- 多标签编辑同一草稿会争抢保存；看到「其它标签正在编辑」提示时不要强行继续。
- 打开另一工程、新建或导入 JSON 前会先强制落盘当前工程；若另一标签占用租约或保存失败，操作会被取消并提示，不会静默丢弃最后一次编辑。

### 3.2 工程库

- `工程库` → 保存当前工程 → 命名；之后自动保存同步到该工程。
- 支持打开、复制、删除；删除不可撤销，重要工程先导出 JSON。
- 未保存到工程库时，版本快照不可用；清除浏览器数据会一并丢失工程库。

### 3.3 合并他人工程

- `工程库` → `合并他人工程…` → 选择对方导出的 JSON。
- 对象按 `updatedAt` 新者胜出，新增并入，删除有墓碑不会复活。
- 合并后若远端配置与本地不同，状态栏/toast 会显示「配置未采纳 N 项 / 配置已补缺 N 项」。**这只说明差异可见，不代表远端配置已生效**：合并始终本地优先。
- 底图与照片不走实时通道，但 JSON 内嵌底图可保留；合并前双方先导出备份。

## 4. 楼层与清空

- **新增/切换/重命名**：顶栏 `楼层`。每层独立底图、场地与对象；图层、类型、工程名、标题栏跨层共享。
- **楼层名必须唯一**：新增/重命名重名被拒；旧工程重名加载只告警；表格导入遇重名整批拒绝，先改名再导入。
- **删除楼层**：该层对象、底图、场地删除，至少保留一层；进入撤销栈可 Ctrl+Z。
- **清空**：顶栏 `清空` 清空当前楼层内容，保留楼层结构、图层、类型、工程名；可 Ctrl+Z。
- **协作**：楼层新增/删除/清空会广播；当前活动楼层切换仍是各客户端独立状态。

## 5. 底图与矢量场地

### 5.1 图片底图

- `底图/场地` 选图片，或把图片拖到画布（拖多个文件只处理第一个）。
- 每层最多 1 张图片底图，导入新图会替换旧图并重置旧图的仿射变换与校准标记，必须重新校准才能按真实比例测量。
- 长边超过 3000 px 会降采样；超大透明图可能转 JPEG。单文件上限见 [features](features.md)§7。

### 5.2 绘制与编辑场地

- `底图/场地` 选矩形/圆形/椭圆/扇形/平行四边形/多边形，在画布绘制；左侧 `场地节点` 拖节点，`属性` 面板精确输入。
- 场地是真实米制，不占对象编号、不进清单/CSV；每层只能有一个，重复绘制会替换。
- 画布、PNG、PDF、SVG、DXF 同步使用新几何；DXF 输出到独立 `SITE` 图层。
- 场地编辑/清空进入撤销栈并广播；对端清空场地会提示，可 Ctrl+Z 恢复。

## 6. 校准图片底图

### 6.1 比例尺（两点定标）

- 前置：当前楼层有已解码的图片底图。`比例尺` → 点两点 → 输入真实距离 → 应用。
- 入口变灰时悬停看原因。比例尺只作用于图片与业务对象，不改场地坐标。

### 6.2 仿射校准

- 已知至少 2 个（建议 ≥3 个）控制点的图像位置与真实坐标。`仿射校准` → 逐点输入 → 应用。
- 2 点为旋转+等比相似；≥3 点为最小二乘完整仿射。控制点尽量分散、不要共线。
- 不提供四角自由拖拽，不能表达任意透视。

### 6.3 图片变换

- 左侧 `图片变换` 拖平移/旋转/缩放/切变手柄；图片角点可吸附场地角点。
- 一般仿射（不等比/切变）下圆/椭圆按主轴精确成像，扇形仅相似变换精确，其余按面积保真近似并在变换摘要标记 `degraded`；这是已披露的降级，不是缺陷。

## 7. 绘制对象与编辑

### 7.1 点设备

- `点设备` → 先选类型/业务类型 → 单击放置；自动编号 `O0001`，跨楼层唯一。
- 导入数据若有重复标识/编号，读入时自动去重或重新编号。

### 7.2 区域与折线

- `区域` 支持矩形/圆形/椭圆/扇形/平行四边形；多边形请用 `折线` 并闭合。
- 扇形跨 0°（如 `350°→20°`）在画布、SVG、DXF 中统一按 30° 处理。
- 折线逐点单击，双击或 Enter 结束；双击线段插节点、双击节点删节点；节点上限 10000，超出拒绝并提示。
- `多边形（polygon）` 形态正常交互不会新建，主要用于兼容异常/外部写入；少于 3 点时面积/周长按 0、不参与命中。

### 7.3 文字、标注与测距

- `文字`：单击定位后输入，支持多行。
- `标注`：两点距离/多点测距/面积/角度；逐点录入，双击或 Enter 完成，可保存并导出。
- `测距` 只显示临时测量线，不落为对象；需要保留请用 `标注`。

### 7.4 选择、移动与批量操作

- `选择` 单击/框选；拖动移动；拖手柄旋转/缩放；方向键微移，Shift ×10。
- `清单` 勾选多个对象 → 批量平移/旋转/改图层/删除/显隐标注/改业务属性，全部进入撤销栈。
- 锁定对象或锁定图层中的对象不可点选/框选。
- 隐藏图层中的对象仍在清单；删除图层/类型前会检查全部楼层引用，有引用时确认后迁移到默认图层/同类内置类型。

### 7.5 图层、类型与标注

- `图层/类型`：图层可新增/改名/显隐/锁定；类型可设颜色、图标与物理尺寸图形。
- 对象标注逐项可选「默认/显示/隐藏」，默认沿用旧全局观感。
- 段长标注有最小屏幕像素（默认 26 px，范围 10–60），缩小后自动隐藏。
- 属性面板只在字段首次输入时记一次撤销，来回切换字段不再占用撤销栈。

## 8. 捕捉与辅助绘图

- 对象捕捉：端点、中点、圆心、象限、垂足、交点、切点；橙色虚线表示 45° 极轴/平行追踪。
- 画布聚焦时 Tab / Shift+Tab 循环捕捉类型；点击底部捕捉徽标恢复自动。
- 画线、标注、拖节点时按住 Shift 约束水平/垂直；拖矩形/椭圆/扇形时 Shift 得正方形/正圆/45° 吸附。
- 可拖出水平/垂直参考线；窗口失焦只结束进行中的交互，保留校准点、参考线与覆盖率。

## 9. 清单与表格批量修改

### 9.1 清单内编辑

- `清单` 双击单元格改名称/坐标/参数；勾选后批量操作。
- 坐标按当前精度四舍五入；输入大数值时先确认单位（米/度）。
- 关键字/类型/图层筛选与「全选」「表头全选」共用同一过滤结果。

### 9.2 表格批量布点

- 先导出 CSV/TSV/XLSX 作模板，保留表头；`导入` → 选表格 → 预览 → 应用。
- 有 `操作` 列：`新增`/`创建`、`更新`、`替换`（可按编号/名称/名称包含/对象类型/业务类型/图层匹配，批量改属性不改几何）。
- 无 `操作` 列：编号命中→更新，否则新增；带匹配列时按匹配列替换。
- 严格模式下任意非法行整批不生效；预览可放弃。
- **有损边界**：单元格去首尾空格；坐标/宽高/角度按当前精度量化，首次往返可能漂移 ≤0.5×10⁻ᵖ；未知「显示/锁定」值保留原值并告警（「闭合」未知值按否）；形状参数非法保留原几何并告警；工程重名楼层整批拒绝；目标楼层对象数据异常时该行拒绝；单表 >5 万行跳过并提示。

## 10. 统计、覆盖率与停车规划

### 10.1 统计

- `统计` 查看数量/面积/长度/楼层汇总与基础问题检查（尺寸过小、节点不足、自相交、超出场地）。
- 统计是快速自检，不等同 `规则` 页的几何检查；基础问题检查只统计可见对象。
- 越界口径自 v2 起与规则页共用场地包围盒与容差（默认 0.05 m），标题与 PDF 报告标注 `v2`；v1 历史报告不可直接比较。

### 10.2 覆盖率分析

- `覆盖率分析` → 设置视场（半径/张角/安装高度/朝向）→ 分析；高亮盲区，可导出盲区 GeoJSON。
- 结果是栅格估算，与视口缩放无关；清除叠加、对象/楼层变更、切层、载入/撤销会释放结果与离屏缓存。
- 面板盲区面积 = 各区域面积×(1−覆盖率) 求和；GeoJSON 盲格面面积另算，两者差异上界约 盲区周长×格宽/2，不要直接对账。

### 10.3 布点优化

- 覆盖率结果弹窗 → `布点优化…` → 填视场/目标覆盖率/最多新增台数 → 应用，自动重跑覆盖率。
- 贪心建议，不保证最优；应用后可撤销；优化前后覆盖率与面板同分母。

### 10.4 停车规划

- `停车规划` → 生成双面垂直车位与共用通道；默认车位 2.5×5.3 m、通道 6 m，通道净宽 <2.5 m 拒绝、<5.5 m 警告。
- 场地可见时只按场地包围盒排布；场地隐藏/缺失才退回「图片∪场地」取景框。
- 生成占用编号（车位 `P001…`、通道 `A001…`）；勾选“先清除”再生成会避开本次墓碑编号并继续递增。

## 11. 导入文件

- 入口：`导入`；JSON/DXF/表格/图片也可拖到画布，**拖多个文件只处理第一个**。
- **JSON**：事务化替换当前工程；失败保持原现场；适合备份/换机/交付。
- **DXF**：仅 ASCII DXF，`.dwg` 先另存；ARC/ELLIPSE/SPLINE/INSERT 展开为折线并在报告给出条数；SOLID/3DFACE/LEADER/ATTRIB/ATTDEF 补解析；`DIMENSION` 等未落地类型跳过并列明；R12 凸度按折线拉直并在预检标注。
- **PDF**：只导入第 1 页，路径/文字转对象；多页提示「共 N 页，已导入第 1 页」；底图只取第 1 页实际绘制的内嵌图，含 `/cm` 的曲线与文字已统一到设备空间。
- **图片**：作为图片底图，需再校准。
- 导入会自动修正重复对象标识与重名；编号与源文件不同属去重结果。

## 12. 导出

| 格式 | 范围 | 要点 |
|---|---|---|
| JSON 工程 | 整工程（全楼层、底图内嵌） | 唯一完整备份 |
| PNG | 当前楼层有效可见对象 | 位图；不绘制草稿/校准线 |
| SVG | 当前楼层有效可见对象 + 场地/标注 | 可无损缩放；底图嵌入 |
| PDF（图纸+清单） | 全楼层有效可见对象 | 图纸页为位图；清单列是台账子集，多楼层按层分页；打印报告单页不标楼层 |
| DXF | 当前楼层有效可见对象 | 场地在独立 `SITE` 图层；坐标毫米，文字按米/度显示 |
| CSV / TSV / XLSX | 全楼层全量对象 | 含隐藏图层，「显示」列按对象与图层都可见标「是」；公式注入防护 |

- 其他产物：报价 CSV/Excel、厂商目录 JSON、二维码标签、盲区 GeoJSON、图框模板。
- 图框/标题栏/图例默认关闭，开启后只作用于 PNG/PDF/SVG。
- PNG/SVG/DXF 只导出当前楼层；需要全楼层用 CSV/TSV/XLSX/PDF。草稿与校准点默认不进入任何导出。

## 13. 协作

### 13.1 同机多标签

- `协作` → `启用本机同步`（默认不自动连接）→ 保持默认频道或输入相同频道名 → 另一标签做同样操作。
- 对象增删改、场地编辑/清空、楼层新增/删除/清空实时同步；按对象/楼层 LWW，较新者胜出。
- 连接建立后会提示“对方拥有完整编辑权”（可覆盖对象、清空楼层/场地、改配置）；同机频道自动会合，不弹确认。
- 接收端按 200ms 节流，只应用最新整工程快照；一次连接内远端最多写入一条撤销历史，不会冲掉你的 20 条撤销。
- 不同工程误用同一频道会串数据；消息带 `pid` 做隔离，草稿需先绑定工程库才能参与。
- 本机频道异常丢失按 1s→2s→…→5min 指数退避自动重连；断线期间改动写本地待发队列，恢复后先补发。

### 13.2 跨设备直连

- 一方创建房间生成邀请文本/二维码，另一方粘贴或扫码。
- 连接建立后会提示“对方拥有完整编辑权”；首次收到对方的整工程快照会弹确认，拒绝即断开且不应用，同一连接只问一次。
- 接收端按 200ms 节流，只应用最新整工程快照；一次连接内远端最多写入一条撤销历史，不会冲掉你的 20 条撤销。
- 无信令服务器；DataChannel 断开后不能自动重连，只能重新交换邀请串。
- 底图/照片不传输；二维码约 42 字节上限，超长请复制文本。
- **真实双设备未验证**：现有 e2e 只用同机双标签；协作安全默认（权限告知 / 首快照确认 / 接收节流 / 撤销栈隔离）有 selftest 39.13b 常驻断言，但不等于真实 DataChannel 行为。

### 13.3 离线合并

- 双方各自导出 JSON → `工程库 → 合并他人工程…`。
- 冲突统计会显示「冲突 N 条（保留较新值）」；只有真正覆盖本地内容才可 Ctrl+Z 回滚。
- 配置差异会显示「配置未采纳/已补缺 N 项」，仅增加可见性，不改变本地优先。

## 14. 版本快照

- 前置：工程已保存到工程库。`工程库` → 工程行版本入口 → 生成快照 → 对比/回滚/叠加查看。
- 对比分类：新增、删除、换楼层、类型变更、移动、属性修改；场景级差异（场地/底图/楼层名/图层名/类型表）排在对象项之后。
- 回滚前当前状态进入撤销栈，可 Ctrl+Z；恢复校验工程归属、schema 与当前工程一致。
- 每工程最多 20 条、约 16 MB（软上限，单条超限仍保留），超出淘汰最旧；对比最多展示 2000 条差异。
- 照片资产化只作用于快照副本；资产库写入失败时保留内嵌 base64 并提示，不静默丢照片。

### 14.1 参照版（图纸修订）

- `设置 → 参照版` 导入另一工程 JSON，仅当前会话有效。
- 差异叠加：新增绿、删除红虚线圈、移动/改动蓝；参照对象半透明垫底，可 1 Hz 闪烁 A/B。
- 标定判定只比图片底图三要素：`metersPerPixel` 相对差 ≤0.1% 视为一致，否则提示「标定不一致」，不自动缩放/平移。
- 参照版不进 state、不进 JSON、不进协作、不进导出；切换/新建/导入工程时自动清空。

## 15. 插件

- `设置 → 插件面板` → 导入清单 → 启用；仅当前会话有效（插件注册的类型会随工程持久化）。
- 插件在 Worker 隔离环境运行，只能使用清单声明能力；单次调用超过 2 秒终止；清单/源码上限按 UTF-8 字节（192 KB / 64 KB）。
- `getState`/`addObjects`/`addAnnotation` 分别限流 60/30/60 次每分钟；导出下载只接受调用期内请求且 ≤32 MB。
- **只加载可信插件**：当前隔离不是完整语言级安全沙箱。

## 16. 设置与界面语言

- `设置`：网格大小/捕捉/点图标大小/十字准星/段长最小像素/场地与面积标注默认/界面语言/参照版/插件。
- 网格线始终落在「网格大小」整数倍坐标上，缩放时按整数倍抽稀，因此每个网格交点都可吸附。
- 中英切换覆盖静态界面、动态面板与无障碍标签；工程名、类型名、备注等业务数据不翻译。
- 英文语义质量尚未人工评审（自动化只证明无中文残留/缺口）。

## 17. 移动端与离线

- 窄屏自动收起侧栏，顶栏 `面板` 切换；触控目标不小于 44 px；单指绘制/移动，双指捏合缩放、平移。
- `file://` 不能安装/离线；PWA 安装与预缓存只对 http/https 多入口成立。
- 更新：出现「新版本可用」后刷新；更新失败不会白屏，可继续用旧版。
- **未验证**：iOS/Android 真机安装与手势、低端机性能。

## 18. 常见问题速查

- **刷新后工程不见**：隐私模式、禁用存储或清理站点数据；从 JSON 导入恢复。
- **底图/照片丢失**：先确认 IndexedDB 可用；PDF 底图已资产入库，正常刷新不丢；仍建议 JSON 备份。
- **导出表里多了隐藏对象**：CSV/TSV/XLSX 保留全量，看「显示」列；PDF 清单与 PNG/SVG/DXF 只输出有效可见对象。
- **表格导入整批拒绝（楼层重名）**：先改名再导入，不会写错层或留半批对象。
- **Ctrl+Z 没反应**：先点画布确认焦点不在输入框；若刚完成批量操作，撤销的是整批。
- **协作方看不到楼层变化**：楼层增删清空已同步；活动楼层切换不同步，改完用离线合并或导出 JSON。
- **DXF 单位对不上**：DXF 坐标毫米、文字按米/度；以几何坐标为准。
- **文件太大导不进**：按 [features](features.md)§7 的上限拆分楼层/工程。
- **协作合并显示配置差异**：只表示远端配置未被采纳/已补缺，本地配置仍生效。
