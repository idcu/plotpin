# 用户手册（User Guide）

> 面向使用者：怎么打开、怎么画、怎么校准、怎么导入导出、怎么协作与装插件。
> 架构与门禁见 [ARCHITECTURE.md](ARCHITECTURE.md) 与 [engineering.md](engineering.md)；能力边界逐条见 [features.md](features.md)。

---

## 1. 打开与首次启动

双击 `index.html` 即可，无需安装、无需联网、无需服务器。也可以用任意静态服务器打开：

```powershell
python -m http.server 8080
npx serve .
```

推荐最新版 Chrome / Edge / Firefox。在线试用地址 <https://idcu.github.io/plotpin/>，数据仍只保存在本机浏览器。

**首次启动引导**：没有任何实际内容的新用户会看到三步上手（载入底图/场地 → 放置对象 → 导出），可选「空白开始」或「打开示例工程」。选择记录存于 localStorage `plotpin:firstRunGuide:v1`：

- 只有走完引导（`completed`）才永久不再出现；`Esc` 或点遮罩只记 `skipped`，下次启动仍会展示。
- 工程已有项目 id / 对象 / 图片底图 / 多楼层 / 非默认场地时视为老工程，不触发引导。
- 示例工程为 100×70 m 矩形场地 + 6 个对象（2 点设备、1 区域、1 折线、1 文字、1 标注），不含图片或照片资产。

> ⚠️ **跨版本兼容**：当前存储为 schema v2（楼层带 `updatedAt`）。旧版 App 只认 v1，会拒绝加载/导入 v2 工程；旧版也不认识 `site` 场地槽，打开新工程会忽略场地。跨版本协作前请统一升级。

## 3. 底图与场地

每层可同时存在 **1 张图片底图 + 1 个矢量场地**，两个槽位独立保存、互不覆盖；替换其中一个不会删除另一个。

### 3.1 图片底图

- 支持 PNG / JPG / WebP / BMP / GIF / SVG；导入后按内容哈希去重存储。
- 单张解码像素上限约 **40 MP**，最长边统一限制 **3000 px**（透明格式在体积允许时保留 PNG 透明）。
- 未导入图片时，「比例尺」「仿射校准」「图片变换」三个入口禁用并通过 `aria-describedby` 给出原因；仅画矢量场地时提示「场地按米绘制，无需校准」。
- 图片尚未解码完成时区分「正在解码」（稍后自动恢复）与「资产缺失」（提示重新导入），不会长期禁用。

### 3.2 矢量场地

- 以米为世界坐标直接绘制：矩形 / 圆形 / 椭圆 / 扇形 / 平行四边形 / 多边形；不进对象列表，不占对象编号与台账行。
- 椭圆数值输入只填长/短轴半径，中心固定世界原点。
- 「场地节点」工具可拖拽控制点调整形状；属性面板可精确输入坐标/参数；多边形支持顶点增删、↑↓ 排序、双击边插点、双击顶点删点。
- 场地标注可逐项开关：边界节点坐标、相邻节点段长、基点/圆心坐标、半径、中心面积、周长。
- 场地显示/锁定跟随所属图层：图层隐藏则不渲染、不计入取景框；图层锁定则控制点不可拖拽。
- 取景框取「图片四角框 ∪ 场地实际包围盒」；渲染顺序固定为图片 → 场地 → 网格/覆盖 → 场地标注 → 业务对象 → 工具手柄。

### 3.3 场地优先校准

存在场地时，图片比例尺/仿射只迁移图片与业务对象，**场地坐标永不自动迁移**（保持真值参考）。需要整体换坐标系时，可在场地属性中显式选择迁移。

## 4. 校准（仅图片底图需要）

校准入口的前置状态由 `calibPrecheck` 统一判断：无图片槽 → 三个入口禁用；图片未就绪 → 按解码中/资产缺失给出原因；可用时顶栏显示步骤。

### 4.1 比例尺（两点定距）

1. 点「比例尺」，在图上点击两个已知点。
2. 输入两点实际距离（米）。
3. 按 `Enter` 或左侧 ✓ 提交，才会统一调用 `applyWorldTransform` 换算出米/像素。

校准点可拖拽调整、`Delete` 删除选中点、`Ctrl+Z` 撤销；未提交前不改动任何对象。

### 4.2 仿射校准

1. 点「仿射校准」，依次点击已知点并输入实地坐标 X、Y。
2. **2 点**求旋转 + 等比缩放（相似变换）；**≥3 点**求最小二乘完整仿射，可纠正底图倾斜与不等比缩放。
3. 同样只有按 `Enter` / ✓ 才真正求解并迁移已有对象；控制点红点改图上像素、绿点改实地坐标。

已仿射校准的底图再次改比例尺不会与对象错位。矢量场地按「场地优先校准」不自动迁移。

### 4.3 图片整体变换

「🖼 图片变换」只提供四类整体变换：橙色中心手柄平移、蓝色圆点旋转、右下角等比缩放、顶边中点切变。**不提供四角自由拖拽**，避免底图被拉成任意四边形；变换只改图片自身，不移动标注对象；图片角点靠近场地边角会自动吸附。

## 5. 绘制与编辑

### 5.1 对象语义

| | 点设备 | 区域 / 折线 |
|---|---|---|
| 表达 | 设备在哪里（位置标记） | 实际占了多大范围（真实几何） |
| 坐标 | 一个锚点 | 世界坐标形状，单位米 |
| 缩放画布 | 图标屏幕大小不变 | 跟随底图缩放，保持真实比例 |
| 大小含义 | 显示倍率（无物理意义） | 实际尺寸（米，参与统计） |

- 点设备：图标大小 = 全局倍率 × 类型默认 × 单个对象覆盖；可填物理尺寸（米）按真实比例渲染覆盖圆/方、摄像头扇形视场、道闸杆。
- 区域支持矩形 / 圆形 / 椭圆 / 扇形 / 平行四边形，属性面板可互换形状（中心不动、等面积换算）；三角形与任意多边形用闭合折线。
- 文字按世界字高放置、可旋转；测距为逐点单击、双击结束、右键/Esc 取消的链式测量。
- 每个对象在各自属性面板单独勾选图上标注（编号、坐标、半径/边长/顶点、周长、面积等）。

### 5.2 编辑

- 点选 / 框选 / 多选（Shift 或 Ctrl/Meta 增量）；移动、缩放、旋转、节点编辑、复制粘贴、删除。
- 多选可按包围盒六向对齐、水平/垂直等间距分布（首末不动）。
- 清单页勾选多个对象后，可用「图上标注」行的「显示标注 / 隐藏标注」统一开关；与属性面板单对象勾选写同一 `annot` 字段，整批一次撤销。平移/旋转数值框保留 ≥92px 可读宽度，触控视口下控件高度 ≥44px，字段名、提交与校验规则不变。
- 批量编号支持前缀/起始/步长并自动避让全工程已有编号；支持置顶/置底。
- 图层显隐与锁定、类型管理、网格吸附、撤销重做（保留 20 条）。
- 拖拽未产生实际位移（<2 px 或拖回原位）不落盘、不留空撤销快照。

### 5.3 绘图辅助

- 对象捕捉：端点、中点、圆心、象限点、垂足、跨对象交点、圆切点，按类型优先级自动吸附；`Tab` / `Shift+Tab` 循环锁定单一类型。
- 按住 `Shift`：画水平/垂直线、拖正方形/正圆、扇形 45° 方位吸附。
- 参考线工具两次点击定义无限长参考线，参与交点/垂足/平行/垂直捕捉。
- `F` 适应窗口；`?` 打开帮助中心（概念词典解释图片底图、矢量场地、楼层、比例尺、仿射、覆盖率口径）。

## 6. 导入

顶栏「导入」或直接把文件拖到画布。

| 来源 | 说明 |
|---|---|
| JSON 工程 | 含底图与全楼层设备照片，单文件可移植；先构建候选并校验限值，成功后才替换现场，失败保留原工程 |
| DXF | 先预检 `$ACADVER` / `$INSUNITS` / 实体数，可改判单位（整体换算），可选「可编辑对象」或「只读参考层」；确认后才事务化提交 |
| PDF | 矢量 PDF 提取路径/文字为可编辑对象；扫描件取最大内嵌图作底图；多页按页树顺序水平排布，每页独立原点 |
| CSV / TSV / XLSX | 表格导入可新增/更新/替换对象；存在「操作」列时严格事务化，非法行整批拒绝 |
| 图片 | PNG/JPG/WebP/BMP/GIF/SVG 作为图片底图或符号来源 |

统一限额（`APP_LIMITS`）：导入文件 ≤ **32 MB**、表格 ≤ **20,000 行**、DXF/PDF 实体 ≤ **100,000**、单工程对象 ≤ **100,000**（含所有楼层）。超限给出明确中文错误，不静默截断。

- `.dwg` 不内置解析：识别 `AC10xx` 版本后提示「转 DXF / 转 PDF / 取消」。
- 二进制 DXF 明确提示另存为 ASCII。
- 表格导入会逐行按几何重算长度/面积/节点数，手改不一致只在预览中告警，以图形几何为准。

## 7. 导出

导出下拉共 **8 种门禁格式**：JSON、PNG、SVG、PDF、DXF、CSV、TSV、XLSX；另有报价表、目录、二维码标签、图框模板、规则 CSV、盲区 GeoJSON。

| 格式 | 要点 |
|---|---|
| JSON | 工程完整往返，底图与全楼层照片内嵌 |
| PNG | 高清位图，含场地标注与可选图框 |
| SVG | 矢量图纸，底图/场地/标注同源输出 |
| PDF | 多页：按楼层顺序逐层输出「图纸页 + 清单页」，页码全局连续；**导出页为位图**，回读不还原矢量坐标 |
| DXF | CAD 互通（R12 ASCII），场地写入独立 `SITE` 图层 `LWPOLYLINE` |
| CSV / TSV | UTF-8 BOM，Excel 直接打开；跨楼层并带楼层列 |
| XLSX | 真 OOXML；单元格一律 `inlineStr` 文本，无公式节点 |

- **字段单一来源**：CSV/TSV/XLSX 表头、PDF/打印报告清单与 SVG/DXF 读数共用 `io-fields.js` 的同一字段表。
- **公式注入防护**：`= + - @`、Tab/CR 开头且非纯数字的单元格加前导单引号；负数与坐标保持数值语义。
- **场地不占台账行**：CSV/XLSX 只含业务对象。
- **图框模板**：可配置工程名/图号/比例/日期/版本/设计/审核/单位，单独开关图框、标题栏、比例尺、图例；**默认关闭**，关闭时三种产物与旧版逐字节一致。
- **设备产品库与 BOM 报价**：目录 JSON 校验 → 落盘 → 才替换内存；报价按「厂商+型号」跨楼层聚合，CSV/XLSX 共用字段表与公式防护；行集合不变时重导沿用冻结单价。

打印/PDF 会生成图纸报告并调用浏览器打印，可另存为 PDF。

## 8. 多楼层、工程库与版本快照

- **楼层**：每层独立图片/场地/对象，共用图层与类型；可新增、切换、重命名、删除。
- **清空**：只清当前楼层的图片、场地、对象、标注、校准运行时状态与选中态，并恢复默认取景框；二次确认，可 `Ctrl+Z` 整体撤销；不改楼层结构、图层与自定义类型。
- **工程库**：把当前图纸另存为命名工程，可打开/重命名/复制/删除；绑定后编辑自动同步。
- **跨楼层**：统计页签按层汇总（对象数/分类/总长/总面积）；打印报告与 PDF 逐层输出；台账覆盖全部楼层并带楼层列。
- **版本快照**：独立命名空间 `snap:<工程>:<快照>`，每工程 20 条 / 16 MB，超限淘汰最旧；照片与底图只存引用。回滚前现场进入撤销栈，可 `Ctrl+Z` 撤回。
- **图纸对比**：A/B 按对象 id 跨楼层匹配，分类新增/删除/属性修改/移动/换楼层/类型变更；叠加层只画当前楼层且不进导出。

## 9. 协作

### 9.1 离线合并（LWW）

工程库「⇄ 合并他人工程…」选择对方导出的 JSON：

- 对象按 id 与 `updatedAt` 较新者胜出，同时间戳用内容签名兜底。
- 删除通过墓碑传播；较新的编辑可让对象复活；墓碑按对象 id 长期保留（上限 2 万条、保留 730 天）。
- 楼层、图层、自定义类型按 id 取并集；活动楼层与本地设置保持不变。
- 合并幂等、结果确定，不需要服务器。

### 9.2 实时协作（无服务器）

- **同机多标签**：`BroadcastChannel` 即时同步，频道名默认复用工程名。
- **跨设备**：WebRTC DataChannel 手动信令，三步建连——主机生成邀请串 → 客机粘贴并生成应答 → 主机粘贴应答完成连接。
- 邀请串为 `PLOTPIN-COLLAB:1:O|A:<base64>`；内置二维码编码器上限 42 字节，装不下邀请串，面板只显示字节数提示，请复制文本发送。
- 本地提交后 500 ms 防抖广播整份可持久化工程；远端按 LWW 合并。存在覆盖时提示「已写入撤销栈，可 Ctrl+Z 回滚」，纯新增不写历史。
- **底图图片与设备照片不走实时通道**，只同步矢量对象、场地与楼层；完整同步用工程库合并或 JSON 导出。
- SDP 含本机网络地址，只发给可信协作方。

### 9.3 多标签编辑保护

- 每个标签页每 5 s 广播心跳，租约 15 s；打开同一工程的另一标签页会在 6 s 内看到「另一标签页正在编辑（最后心跳 HH:MM:SS）」。
- 可选「重新载入」或「仍以本页为准」（后者需确认，取得租约后本页不再提示）。
- 冲突未解除时自动保存暂缓，已编辑内容只驻内存、不丢。
- `BroadcastChannel` 不可用时降级 `storage` 事件；两者都不可用则提示「无法检测多标签页，编辑仍可用」，不阻塞编辑。
- 该能力**不做实时互斥**，写入仍是最后写者覆盖。

## 10. 数据保存与故障处理

- 编辑后 **450 ms 防抖**自动保存到 IndexedDB（`current` 草稿）；IndexedDB 不可用时降级 localStorage，并明确提示。
- 加载前经 `auditProject` 审计：schema、楼层结构、活动楼层、对象 id 唯一、图层引用、`background/site` 形状。结构性错误阻断载入并保留原始文本，普通异常降级为横幅告警。
- IndexedDB 记录损坏时回退 localStorage 备份并提示来源；两者皆坏进入空工程，但横幅与「导出救援 JSON」入口可见。结构性错误期间暂停自动保存，避免空工程覆盖原记录。
- 保存失败分类：
  - 配额耗尽（`QuotaExceededError`）**不自动重试**，提示导出 JSON / 清理空间。
  - IndexedDB 不可用降级 localStorage。
  - 其余瞬时写入错误按 **1 s / 3 s / 9 s** 退避重试 **3 次**后停止。
- 失败横幅常驻，下一次成功保存自动清除；状态栏只在真实成功时显示「已保存」。
- 资产按命名空间可达集回收（草稿、撤销/重做栈、剪贴板、拖拽原件、工程库、快照），打开/新建/删除任一工程不会误删其他工程的底图与照片。

## 11. 插件

### 11.1 导入与管理（会话内）

设置 → 插件面板可导入 `plotpin.plugin/v1` 清单：

```json
{
  "schema": "plotpin.plugin/v1",
  "id": "example",
  "name": "示例插件",
  "version": "1.0.0",
  "apiVersion": "1.0",
  "capabilities": ["state:read", "export"],
  "code": "PlotPin.registerExporter({ ... })"
}
```

- 必填 `schema / id / name / version / apiVersion / capabilities / code`；清单 ≤ **192 KB**，`code` ≤ **64 KB**。
- 校验失败不改注册表；导入前展示能力确认，确认后才加载。
- **仅本会话有效**，刷新后需重新导入；面板可逐条卸载。

### 11.2 沙箱与能力

- `PlotPin.loadPlugin({id, apiVersion, capabilities, code})` 在独立 Worker 执行：无 DOM / `window` / `parent`，`fetch` / `indexedDB` / `XMLHttpRequest` / `WebSocket` / `importScripts` / `caches` 已删除。
- 能力白名单：`state:read`、`state:write`、`annotate`、`types`、`icons`、`export`、`import`、`rules`；未声明一律拒绝。
- 初始化与单次调用 **2000 ms** 超时即 terminate，插件进入 disabled 并显示原因；主工程不受影响。
- 版本规则：宿主 API 1.1.0；`1.0` / `1.0.0` / `1.1` 通过；`1.2` 次版本高于宿主拒绝；`2.0` 主版本拒绝；缺失/畸形拒绝并给中文原因。
- 规则：`PlotPin.registerRule(def, owner?)` / `unregisterRule` / `listRules`；沙箱 Worker **不能注册规则**，须经受信任同源路径，`owner` 用于规则页签来源标识。
- 旧同源 `<script>` 路径保留为受信任兼容入口，拥有完整页面权限，**不做能力沙箱**。

可运行示例：[plugins/sample-sandboxed.js](../plugins/sample-sandboxed.js) 与 [plugins/sample-exporter.js](../plugins/sample-exporter.js)。

## 12. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 比例尺/仿射/图片变换按钮不可用 | 当前层没有图片底图，或图片尚未解码完成；按钮旁 `aria-describedby` 有具体原因 |
| 只有矢量场地却提示无需校准 | 场地按米绘制，本身已是真实坐标；校准只服务图片底图 |
| 首次引导又出现了 | 上次只记了 `skipped`；走完三步或点「空白开始」才记 `completed` |
| 状态栏显示「请手动导出」 | 保存失败；按横幅提示处理配额/IO 问题，或立即导出 JSON |
| 出现「另一标签页正在编辑」 | 同工程在另一标签编辑；选择重新载入或确认以本页为准 |
| 刷新后插件不见了 | 插件仅本会话有效，重新导入清单 |
| 协作邀请二维码不显示 | 邀请串超过内置二维码 42 字节上限，只显示字节数；请复制文本发送 |
| 导出的 PDF 不能在别处继续编辑 | PDF 导出页是位图；需要可编辑矢量请用 SVG 或 DXF |
| Excel 里表格单元格带前导单引号 | 公式注入防护；纯数字与负数不受影响，导入时会自动还原 |
| 旧版 App 打不开新工程 | 存储已升级到 schema v2；请统一升级版本 |
