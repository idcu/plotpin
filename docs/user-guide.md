# 图钉 PlotPin 用户手册

> 面向最终用户，按任务组织。每节给出前置条件、操作路径、预期结果与常见坑。
> 功能边界见同目录的《功能说明》，缺陷与未验证项见《已知问题》。本文不涉及内部实现。

## 1. 打开与安装

- **前置**：使用桌面版 Chrome / Edge（推荐最新版）。首次使用无需账号或网络。
- **操作**：双击发行包中的 HTML 文件，或在静态服务器 / HTTPS 地址中打开。
- **预期**：出现“工程库 / 新建 / 导入”和空白画布；本机数据自动载入。
- **常见坑**：
  - 双击打开（本地文件模式）可以正常绘图和导出，但**不能安装为应用、不能启用离线缓存**。
  - 需要安装或离线使用时，必须通过 `http://` 或 `https://` 打开。
  - 浏览器隐私模式、禁用存储或清理站点数据会丢失本机草稿，重要图纸请导出 JSON 备份。

## 2. 首次启动与界面

- **首次启动**：若本机没有有效工程，会提示新建或载入示例工程。示例工程不含图片资产，可放心试用。
- **顶栏**：新建、工程库、楼层、导入、导出、打印、底图/场地、比例尺、仿射校准、覆盖率分析、停车规划、协作、面板、设置、清空、撤销/重做、缩放与适应。
- **左侧工具栏**：选择、平移、点设备、区域、折线、文字、测距、标注。
- **右侧页签**：属性、清单、图层/类型、符号库、统计、规则。
- **预期**：新建后即可直接绘制矢量场地并布点，无需先导入底图。

## 3. 新建、保存与工程库

### 3.1 新建与自动保存

- **前置**：无。
- **操作**：顶栏 `新建` → 输入工程名（可留空）。
- **预期**：得到空白工程；修改后约半秒自动保存草稿，右上角显示保存状态。
- **常见坑**：多标签同时编辑同一草稿会争抢保存，看到“其它标签正在编辑”提示时不要强行继续。

### 3.2 另存为工程库工程

- **前置**：已完成至少一次绘制（纯空白不算有效工程）。
- **操作**：顶栏 `工程库` → 保存当前工程 → 命名。
- **预期**：工程出现在工程库列表；之后自动保存会同步到该工程。
- **常见坑**：未保存到工程库时，版本快照不可用；清空浏览器数据会一并丢失工程库。

### 3.3 打开、复制、删除工程

- **操作**：`工程库` → 选择工程 → 打开 / 复制 / 删除。
- **预期**：打开会切换当前工程；删除会移除该工程与其快照。
- **常见坑**：删除不可撤销；重要工程先导出 JSON。

### 3.4 合并他人工程

- **前置**：对方已导出 JSON。
- **操作**：`工程库` → 合并他人工程… → 选择 JSON。
- **预期**：同编号对象按更新时间取较新版本，新增对象并入，删除不会复活。
- **常见坑**：底图/照片不走该流程的实时通道，但 JSON 内嵌底图可保留；合并前双方都应先导出备份。

## 4. 楼层与清空

### 4.1 新增 / 切换 / 重命名楼层

- **操作**：顶栏 `楼层` → 新增楼层 / 点击楼层切换 / 重命名。
- **预期**：每层有独立的底图、场地和对象；图层、类型、工程名与标题栏跨层共享。
- **常见坑**：**楼层名必须唯一**。新增/重命名与已有楼层重名会被拒绝并提示；旧工程若已存在重名楼层，加载只告警，表格导入会在预览阶段整批拒绝，请先改名再导入。

### 4.2 删除楼层

- **操作**：`楼层` → 删除当前楼层。
- **预期**：该层对象、底图、场地删除，其余楼层不受影响；至少保留一层。
- **常见坑**：删除会进入撤销栈，可 Ctrl+Z 恢复；但删除当前楼层会切换到其它楼层，撤销前不要继续编辑；重要图纸先导出 JSON。

### 4.3 清空当前楼层

- **操作**：顶栏 `清空` → 确认。
- **预期**：清空当前楼层的底图、场地、对象与标注，保留楼层结构、图层、类型、工程名。
- **常见坑**：清空后可用 Ctrl+Z 撤销；不要同时切换楼层，否则撤销栈指向的现场可能已变化。

## 5. 底图与矢量场地

### 5.1 导入图片底图

- **前置**：准备 PNG / JPG / WebP；单文件不超过 32 MB。
- **操作**：顶栏 `底图/场地` → 选择图片；或将图片拖到画布。
- **预期**：图片作为底图铺到当前楼层，可校准、平移、旋转、缩放。
- **常见坑**：长边超过约 3000 px 会被降采样；超大透明图可能被转成 JPEG，透明区域变白/黑。每层只保留一张图片底图，导入新图会替换旧图。

### 5.2 绘制矢量场地

- **前置**：无。
- **操作**：`底图/场地` → 选择矩形/圆形/椭圆/扇形/平行四边形/多边形 → 在画布绘制；或左侧 `场地节点` 编辑已有场地。
- **预期**：得到按米制绘制的真实场地；无需校准即可布点；场地优先于图片。
- **常见坑**：场地不是业务对象，不占编号、不进清单/CSV；每层只能有一个场地，重复绘制会替换。

### 5.3 编辑场地

- **操作**：左侧 `场地节点` → 拖节点；`属性` 面板精确输入尺寸/半径/角度；标注逐项开关。
- **预期**：画布、PNG、PDF、SVG、DXF 同步使用新几何；SVG/DXF 补齐场地标注与独立图层。
- **常见坑**：每次进入属性面板或开始拖点会压入一层历史，可 Ctrl+Z 回退；协作时改动会实时同步，对端清空场地会提示并可用 Ctrl+Z 恢复。

## 6. 校准图片底图

### 6.1 比例尺（两点定标）

- **前置**：当前楼层有图片底图，且图片已解码完成。
- **操作**：顶栏 `比例尺` → 在图上点两点 → 输入这两点的真实距离 → 应用。
- **预期**：图片按比例与旋转对齐；对象坐标落到真实米制。
- **常见坑**：入口变灰时，把鼠标移到按钮上查看原因（底图缺失、解码中、已有场地等）；比例尺只作用于图片，不改场地坐标。

### 6.2 仿射校准

- **前置**：已知至少 2 个（建议 3 个以上）控制点的图像位置与真实坐标。
- **操作**：顶栏 `仿射校准` → 依次点图像点并输入真实 X/Y → 应用。
- **预期**：2 点为旋转+等比相似；3 点及以上为最小二乘完整仿射。
- **常见坑**：控制点尽量分散，不要共线；场地存在时，校准只改图片与业务对象，不会移动场地。

### 6.3 图片变换

- **操作**：左侧 `图片变换` → 拖平移/旋转/缩放/切变手柄；图片角点可吸附场地角点。
- **预期**：只改图片与业务对象，场地保持不动。
- **常见坑**：不提供四角自由拖拽；旋转到 90° 附近时切变手柄可能退化；一般仿射下圆/椭圆/平行四边形会变形（已知问题）。

## 7. 绘制对象与编辑

### 7.1 点设备

- **操作**：左侧 `点设备` → 单击放置；先选类型/业务类型；放置后立即编号。
- **预期**：自动编号形如 `O0001`，跨楼层唯一；右侧 `属性` 可改名称、坐标、类型、图层、显隐、锁定。
- **常见坑**：点太密时可能叠在一起，先放大再放置；导入的数据若带重复编号/标识，读入时会自动加后缀或重新编号。

### 7.2 区域

- **操作**：左侧 `区域` → 选矩形/圆形/椭圆/扇形/平行四边形 → 拖拽或逐点绘制（多边形请用 `折线` 并闭合）。
- **预期**：真实比例的区域；可显示面积/周长/边长/顶点/节点标注。
- **常见坑**：扇形跨 0° 时画布与 SVG 的角度可能不一致（已知问题）；一般仿射下形状会失真。

### 7.3 折线、文字、标注

- **折线**：逐点单击，双击或 Enter 结束；双击线段插入节点，双击节点删除节点。
- **文字**：单击定位后输入；支持多行。
- **标注**：两点距离 / 多点测距 / 面积 / 角度；逐点录入，双击或 Enter 完成。
- **测距**：左侧 `测距` 只显示临时测量线，不保存为对象；要保留请用 `标注`。
- **常见坑**：绘制中按 Esc 或右键取消；Backspace 删除上一个节点；双击结束不会重复生成节点。

### 7.4 选择、移动与批量操作

- **操作**：`选择` 工具单击/框选；拖动移动；拖手柄旋转/缩放；方向键微移（Shift ×10）。
- **批量**：右侧 `清单` 勾选多个对象 → 批量平移 / 旋转 / 改图层 / 删除 / 显示或隐藏标注 / 修改业务属性。
- **预期**：所有批量操作进入撤销栈，可按 Ctrl+Z 回退。
- **常见坑**：隐藏图层中的对象仍在清单中；删除图层/类型前会检查全部楼层的引用，有引用时先确认再迁移到默认图层 / 同类内置类型，不会留下悬空引用。

### 7.5 图层、类型与标注开关

- **操作**：右侧 `图层/类型` → 新建/改名/显隐/锁定图层；新建类型并设置颜色、图标、物理尺寸图形。
- **对象标注**：`属性` → 标注分组 → 每项可选“默认/显示/隐藏”；默认值沿用旧全局观感。
- **常见坑**：隐藏图层不会从 CSV/TSV/XLSX/PDF 清单中移除；段长标注有最小屏幕像素限制（默认 26 px），缩小后自动隐藏。

## 8. 捕捉与辅助绘图

- **对象捕捉**：端点、中点、圆心、象限、垂足、交点、切点；画线时橙色虚线表示 45° 极轴/平行追踪。
- **切换捕捉**：画布聚焦时 Tab / Shift+Tab 循环；点击底部捕捉徽标恢复自动。
- **正交**：画线、标注、拖节点时按住 Shift 约束水平/垂直；拖矩形/椭圆/扇形时 Shift 得正方形/正圆/45°吸附。
- **参考线**：可拖出水平/垂直参考线，用于对齐。
- **常见坑**：捕捉候选太多时按 Tab 切换或临时关闭；极轴追踪与对象捕捉会同时生效，注意当前高亮。

## 9. 清单与表格批量修改

### 9.1 清单内编辑

- **操作**：右侧 `清单` → 双击单元格编辑名称/坐标/参数；勾选后批量操作。
- **预期**：修改即时生效并进入撤销栈；排序/筛选不影响对象本身。
- **常见坑**：坐标按当前精度四舍五入；旋转/平移输入框较窄，输入大数值时先确认单位（米/度）。

### 9.2 用表格批量布点

- **前置**：先导出一份 CSV/TSV/XLSX 作为模板，保留表头。
- **操作**：顶栏 `导入` → 选择表格 → 预览 → 应用。
- **模式**：
  - 有 `操作` 列：`新增`/`创建`、`更新`、`替换`；`替换` 可按编号/名称/名称包含/对象类型/业务类型/图层匹配，批量改属性但不改几何。
  - 无 `操作` 列：编号命中则更新，否则新增；带匹配列时按匹配列替换。
- **预期**：严格模式下任意非法行会导致整批不生效；预览可放弃。
- **常见坑**：表格往返不是逐字节无损，单元格会去首尾空格（名称/备注的首尾空格会丢失）；坐标/宽高按当前精度（默认 2 位小数）四舍五入，首次往返可能产生 ≤0.5 cm 漂移；无法识别的 `显示`/`锁定` 值会保留原值并告警（`闭合` 的未知值仍按否处理）；形状参数非法时保留原几何并告警（不会再出现 X/Y 已改、宽高没改的半套状态）；工程存在重名楼层时整批拒绝，请先改名；目标楼层对象数据异常时该行会被拒绝，不会写进当前楼层；单表超过 5 万行会被跳过并提示，其余工作表继续导入；全部超限才失败，请拆分。

## 10. 统计、覆盖率与停车规划

### 10.1 统计

- **操作**：右侧 `统计` → 查看数量/面积/长度/楼层汇总与基础问题检查。
- **预期**：快速发现尺寸过小、节点不足、自相交、超出场地等问题。
- **常见坑**：统计页的检查是快速自检，和 `规则` 页的几何检查口径不同，结论可能不一致。

### 10.2 覆盖率分析

- **操作**：顶栏 `覆盖率分析` → 设置视场（半径/张角/安装高度/朝向）→ 分析。
- **预期**：显示覆盖率与盲区高亮；可导出盲区 GeoJSON（坐标按当前精度取整、外环逆时针，退化面不导出）；结果与缩放无关。
- **常见坑**：覆盖率是栅格估算；圆/椭圆/扇形按固定段数采样；旧版口径的结果不可直接比较。面板盲区面积按多边形面积×(1-覆盖率) 算，导出的 GeoJSON 面面积按盲格数×格面积算，两者差异上界约为盲区周长×格宽/2，不要拿两个数直接对账。

### 10.3 布点优化

- **操作**：覆盖率结果弹窗 → `布点优化…` → 填目标覆盖率/最多新增台数 → 应用。
- **预期**：给出新增点位并自动重跑覆盖率。
- **常见坑**：只做贪心建议，不保证最优；应用后仍可撤销。优化前后覆盖率与覆盖率面板使用同一分母（区域总面积），不会出现两个百分比各算一套。

### 10.4 停车规划

- **操作**：顶栏 `停车规划` → 确认当前场地 → 生成。
- **预期**：双面垂直车位与共用通道；默认车位 2.5×5.3 m、通道 6 m；通道净宽 <2.5 m 拒绝生成。
- **常见坑**：按“图片∪场地”取景框计算，图片大于场地时可能排到场地外；生成结果会占用对象编号。

## 11. 导入文件

- **入口**：顶栏 `导入`（PDF 也走这里）；JSON/DXF/表格/图片也可直接拖到画布。
- **JSON**：事务化替换当前工程；失败保持原现场。适合备份、换机、交付。
- **DXF**：仅 ASCII DXF；`.dwg` 请先在 CAD 另存为 DXF；R12 凸度按折线拉直；可落到只读参考层。
- **PDF**：提取内嵌图作为底图，路径/文字转为对象；多页沿 +X 排布，不叠加；多页时只取一张内嵌图作底图，可能不是对象所在页。
- **图片**：作为图片底图，需再校准。
- **常见坑**：
  - PDF 内嵌底图会自动入库，刷新/重开后仍可用；若浏览器禁用 IndexedDB，则仅在本次会话有效并提示。导入后仍建议导出一份 JSON 备份。
  - 含 `/cm` 变换的 PDF，曲线与文字可能错位（待修）。
  - 单文件 32 MB、实体 10 万、表格 2 万行、对象总数 10 万；超大折线可能崩溃。
  - 导入会自动修正重复对象标识与重名（`OBJ1_2` / `O0001` 等）；若发现编号与源文件不同，属去重结果。

## 12. 导出

- **入口**：顶栏 `导出` 下拉；`打印` 走浏览器打印/另存 PDF。

| 格式 | 范围 | 要点与坑 |
|---|---|---|
| JSON 工程 | 整工程（全楼层、底图内嵌） | 唯一完整备份；PDF 底图风险用它兜底 |
| PNG 高清图 | 当前楼层有效可见对象 | 位图，放大不保真；不绘制草稿/校准线 |
| SVG 矢量图 | 当前楼层有效可见对象 + 场地/标注 | 可无损缩放；底图嵌入 |
| PDF（图纸+清单） | 全楼层有效可见对象 | 图纸页是位图；清单独立分页，只列有效可见对象；清单列是台账子集（无楼层/备注/更新时间），多楼层按层分页；打印报告单页、不区分楼层 |
| DXF | 当前楼层有效可见对象 | 场地在独立 `SITE` 图层；坐标毫米 |
| CSV / TSV | 全楼层全量对象 | 含隐藏图层，但「显示」列按有效可见标注；公式注入防护；TSV 带引号的值在 Excel 中可能错列 |
| XLSX | 全楼层全量对象 | 文本写入，无公式；含隐藏图层，但「显示」列按有效可见标注 |

- **其他产物**：报价 CSV/Excel（需属性里有厂商/型号/数量）、厂商目录 JSON、二维码标签、盲区 GeoJSON、图框模板。
- **图框/标题栏/比例尺/图例**：导出下拉选 `图框模板…`；默认关闭，开启后只作用于 PNG/PDF/SVG。
- **常见坑**：
  - PNG/SVG/DXF 只导出当前楼层；需要全楼层请用 CSV/TSV/XLSX/PDF。
  - CSV/TSV/XLSX 台账不按图层过滤，隐藏图层的对象仍在；判断是否真正可见请看「显示」列（对象与图层都可见才标「是」）。PDF 图纸与清单、PNG/SVG/DXF 只输出有效可见对象。
  - 未完成的绘制草稿与校准点不会进入 PNG/PDF/SVG/DXF；需要把草稿作为正式对象请先完成绘制。
  - DXF 的场地图层名为 `SITE`，与用户自建同名图层可能混淆。
  - DXF 坐标是毫米，但文字标注按米/平方米/度显示，CAD 内不要按文字数值直接量取。

## 13. 协作

### 13.1 同机多标签

- **操作**：顶栏 `协作` → 保持默认频道或输入相同频道名 → 在另一个标签打开同一地址并连接。
- **预期**：对象增删改实时同步；每层对象按更新时间取较新版本。
- **常见坑**：频道名会记住上次输入；不同工程误用同一频道会串数据。场地编辑与清空会同步（对端清空可 Ctrl+Z 恢复）；楼层的增删改与切换不同步。

### 13.2 跨设备直连

- **操作**：一方创建房间并生成邀请文本/二维码；另一方粘贴邀请或扫码连接。
- **预期**：局域网直连后对象实时同步。
- **常见坑**：二维码最多约 42 字节，超长会改用可粘贴文本；断线后不会自动重连，也不补发断线期间的修改；底图/照片不传输。真实双设备场景尚未验证。

### 13.3 离线合并

- **操作**：双方各自导出 JSON → `工程库 → 合并他人工程…`。
- **预期**：新增并入、较新版本胜出、删除不复活。
- **常见坑**：合并不会提示“谁覆盖了谁”的冲突条数；合并后立即导出 JSON 备份。

## 14. 版本快照

- **前置**：工程已保存到工程库。
- **操作**：`工程库` → 工程行版本入口 → 生成快照 → 选择两条对比 / 回滚 / 叠加查看。
- **预期**：对比列出新增、删除、换楼层、类型变更、移动、属性修改；回滚前当前状态进入撤销栈，可 Ctrl+Z 再回来。
- **常见坑**：每工程最多 20 条、约 16 MB（UTF-8 字节估算的软上限，单条超限仍保留），超出淘汰最旧；对比会列出对象项与场景级项（场地/底图/楼层名/图层名/类型表结构），列表最多展示 2000 条差异，超出部分没有差异导出入口（弹窗里“快照记录”指存储记录，不是差异明细）；叠加只在当前楼层显示，不进入导出。

## 15. 插件

- **前置**：拿到可信来源的插件清单文件。
- **操作**：`设置 → 插件面板` → 导入清单 → 启用。
- **预期**：插件在隔离环境中运行，只能使用清单声明的能力；单次调用超过 2 秒会被终止。
- **常见坑**：插件仅当前会话有效，刷新后需重新导入；插件写入的对象不能撤销；当前隔离不是完整安全沙箱，**只加载可信插件**；长任务/定时器可能不被超时限制。

## 16. 设置与界面语言

- **操作**：顶栏 `设置` → 网格大小/捕捉/点图标大小/十字准星/段长最小像素/场地与面积标注默认/界面语言/插件。
- **预期**：设置即时生效，保存在本机；中文/English 切换后静态界面、动态面板与无障碍标签一起变化。
- **常见坑**：工程名、类型名、备注等业务数据不翻译；英文质量尚未人工评审。

## 17. 移动端与离线

- **移动端**：窄屏自动收起侧栏，顶栏 `面板` 切换；触控目标不小于 44 px；单指绘制/移动，双指捏合缩放、拖动平移。
- **安装**：通过 `https://` 或 `http://` 打开 → 浏览器菜单“安装应用/添加到主屏幕”。
- **离线**：安装后缓存按版本更新；出现“新版本可用”提示后刷新即可；更新失败不会白屏，可继续用旧版。
- **常见坑**：本地文件模式不能安装/离线缓存；iOS 安装与手势、Android 低端机性能尚未真机验证。

## 18. 常见问题速查

- **底图/照片丢了**：先确认 IndexedDB 是否可用；PDF 底图已改为资产入库，正常刷新不会丢。仍建议用 JSON 备份恢复。
- **导出的表里多了隐藏对象**：CSV/TSV/XLSX 台账保留全量，看「显示」列即可区分；PDF 清单与 PNG/SVG/DXF 只导出有效可见对象。
- **导出的图里有半截线**：草稿/校准已默认不进 PNG/PDF/SVG/DXF；若仍有，检查是否已落成正式对象或开启了图框模板。
- **表格导入被整批拒绝（提示楼层重名）**：先到 `楼层` 把重名楼层改成唯一名称后重新导入；不会写错层或留下半批对象。
- **Ctrl+Z 没反应**：属性面板输入框刚获得焦点时可能多压了一层历史；先点画布再撤销（已知问题）。
- **场地改了撤不回去**：确认撤销前没有再切层或新建；场地编辑会进入撤销栈，属性面板输入后若焦点仍在输入框，先点画布再按 Ctrl+Z。
- **协作方看不到楼层变化**：场地与对象会同步；楼层新增/删除/改名/切换仍不同步，改完用离线合并或重新导出 JSON。
- **DXF 单位对不上**：DXF 坐标是毫米，文字标注按米/度显示；以几何坐标为准。
- **文件太大导不进**：单文件 32 MB、对象 10 万、表格 2 万行；先拆分楼层/工程。
- **刷新后工程不见了**：可能处于隐私模式、禁用存储或清理了站点数据；从 JSON 导入恢复。
